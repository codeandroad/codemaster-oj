# 学生、登录与个人资料原型对齐记录

对照基准：相邻独立原型 `../myoj-prototype/src/components/` 的学生工作台、题库、编程工作区、作业、学习路径、提交、订正本、计时训练、登录、注册与个人资料，以及该仓库 `docs/campus-judge-final-design.md` 第 3、4、8 节。生产模块独立实现，不导入或构建原型文件。共享导航、布局和颜色由生产公共组件提供。

## 保留的生产语义

原型中的演示状态选择器、固定样例用户、假成绩和“保存预览”提示没有接入生产逻辑。外观遵守同样的页面结构、表格、页签、按钮和确认窗口；内容显示真实用户与真实数据库状态。

编辑器只在浏览器保存当前会话的代码草稿，草稿键按账号、来源、题目与版本隔离，不保存激活码或密码。内部返回和离开浏览器都有未提交编辑提示；服务端收到的代码与草稿分开。代码运行由判题服务隔离执行，Web/API 不执行学生代码。

公开样例通过显示“样例全部通过”；自定义运行只表示执行与输出，未提供期望答案时不显示 AC。评分、适用范围、固定版本、截止时间、计时训练末次提交选择、成绩遮蔽和订正权限由服务端决定。

修复了旧接口先截取最近 200 条混合记录、再由浏览器排除自测的问题：大量公开自测不再挤走正式历史，也不会让题库误显示“未开始”。题库汇总遍历本人完整正式提交，原提交与订正分开；提交表格沿用原型布局，分页与筛选由服务端执行，游标不暴露私有评测数据。

工作区的“我的提交”在服务端先限定当前题目，来自作业或计时训练时再限定当前活动；普通题库及订正工作区保留此题跨版本的正式/订正记录。提交页筛选使用服务端实际支持的 11 种显示状态，包括未公布真实成绩时的 `Executed`；筛选变化会从第一页重新开始。

## 验证证据

- 已通过学生/auth/code-comparison 专项 ESLint，`--max-warnings 0`；已通过 Web TypeScript 检查。
- 在实际本地生产服务上使用已有学生账号验证登录、工作台、题库搜索、收藏保存与恢复、作业列表/详情、路径列表/详情/章节、训练规则、提交详情、订正抽屉、订正详情、个人资料和独立工作区。
- 实际公开样例评测得到样例通过，自定义函数输入实际执行并显示“仅展示程序输出，未判断正确性”；验证 Reset 确认。它们只新增公开自测记录，未改变原活动成绩。
- 订正详情实际显示原提交 75/100 和独立订正 100/100，并分别呈现代码与教师人工反馈。
- 在 1440px 桌面与原型副本比较工作台列宽、工作区 44%/56% 分割、深色编辑区、行号、结果区域及底部动作位置。
- 最后一次实际生产重建后的只读检查通过：覆盖 16 个学生页面各 1440px/390px，以及 390px 的登录/注册；所有页面无文档横向溢出。确认原作业仍为 75 分、二维列表教学完整、教师反馈没有进入个人笔记。提交详情测试表格在内部滚动，共享标题栏和工作区动作组正常适配。
- 使用独立临时数据库与隔离代理验证章节“已读→取消→已读”，每一步读取真实 API 并重新加载页面确认持久化，全部通过；没有改动种子学生的阅读状态。另验证编辑器草稿重载恢复，未向服务器提交代码。
- 独立订正详情接口的服务端集成验证通过：原笔记被 205 条较新的笔记挤出列表后仍能直接读取；返回完整原始/订正笔记链及最新订正 ID；无关身份访问返回 403。
- 最终实际部署（包含迁移 012、完整历史汇总和分页接口）专项只读验收通过：全部 11 个 Verdict、4 个 Context 与现有 2 个 Problem 筛选项均得到成功且正确过滤的服务端响应；筛选均重置为第 1 页。真实签名游标读取下一条正式记录，没有重复；公开自测未出现在正式表格。
- 最终题库表及 API 均保留原始 `WA`、Best `75.00/100`，独立订正 `100/100` 没有覆盖它。工作区按当前题目读取原始/订正记录；尚无提交的新作业工作区不会继承其他活动记录。390px 提交历史、工作区及独立订正详情无文档横向溢出，分页按钮正常排列，三个已保存笔记标签可准确读取。
- 修复了阅读进度更新时暂时卸载正文、丢失成功提示的问题；已有数据刷新期间保留页面和表单，首次加载仍显示加载状态。
