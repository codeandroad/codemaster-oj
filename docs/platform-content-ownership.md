# 平台课程题目归属与编辑授权

2026-11-13：课程迁移必须同时迁移关联普通题目的管理归属。110 增量迁移将现有平台课程关联的 `problems.owner_scope` 改为 `platform`，保留题目、版本、章节、分组引用、历史作者、历史提交与成绩。学校字段继续作为历史存储命名空间，不代表维护权限。

课程内练习不再要求先进入全平台公开题库。按当前课程范围与准入权限提供学习及判题访问，访问不授予原学校身份或其他题库权限，隐藏测试仅发给隔离执行器。已公开的普通题继续保留原公开入口。

2026-11-13 后续修正：学校题库、平台题库及课程普通练习均读取同一道题的当前已审核发布版本，旧链接或历史 AC 不会使学习入口停留在旧版。课程存储的关联版本保留为审计记录，不再决定普通练习的当前版本；新草稿仍不对学生开放。个人 AC、提交次数及最高分按稳定题目身份跨学校／平台入口和历史版本归集，课程完成度继续遵守语言要求和考试成绩公开规则。原始提交、正式活动成绩及 ACSL 试卷版本不重写。

平台的题目维护与公开审核合并到「公开题库」，平台来源显示为 CodeMaster。课程与题目列表均提供单项及批量「编辑授权」。授权绑定具体内容、账号及学校，支持学校管理员和老师；不得授权学生。获授权内容直接出现在该学校原有课程／题库列表中，账户菜单不再增加单独入口。平台与受托人员复用学校现有的完整课程／题目编辑器，旧授权工作区链接返回学校管理列表。撤销、账号失效或学校教学身份失效后无法继续编辑。所有授权及撤销写入平台审计。

2026-11-13 按用户要求进一步调整：课程授权实时覆盖该课程当前有效章节关联的平台普通题目，已有课程授权无须重新授予。移除关联、归档课程或撤销课程授权会结束相应派生权限，其他有效课程或直接题目授权继续生效。题目授权不反向授予课程权限，课程授权也不改变非平台题目的权限。受托者新增题目关联前须已具该题编辑权限，防止通过添加任意关联自行扩大授权。

获授权者可修改课程内容及关联、保存题目新版本、验证参考解、编辑教程和题解草稿；题解发布、课程发布、下架、归档、恢复、准入规则及题目发布仍仅限平台管理员。原学校管理员或历史作者身份不再提供平台题目的修改权。ACSL 课程正文适用显式授权，ACSL 试卷与答案仍保留原独立访问及发布边界。

110 归属迁移与编辑授权实施时的验证覆盖真实 NestJS、PostgreSQL `campus_app` 权限、迁移保留、课程题目打开与提交、隐藏测试不泄露、受限课程访问、编辑授权/撤销/离校失效、并发修订、学校与平台发布隔离。真实执行器验证普通题提交及 Python/C++/JavaScript 沙箱限制。部署使用增量迁移，保留数据库卷和所有学生记录。

本轮工作流整合不更改数据归属、学习进度或判题执行方式。平台编辑适配接口复用既有题目版本、教程及题解领域逻辑，逐请求核验内容授权；学校列表只并入该学校的有效授权项。旧学校发布及题解批量发布接口也不得绕过平台发布权限。

平台题库分类独立存储，不替换题目的原学校题库 ID。筛选支持来源、分类、关联课程及状态；上传可批量导入草稿，服务端整批校验并以幂等键防止重复导入。批量移动分类保留同一题目及版本。删除采用可恢复的归档，撤回独立公开但保留历史；仍被有效课程、作业或训练引用的题目必须先解除关联，整批操作失败不产生部分删除。公开范围与发布始终需要平台管理员明确操作。

平台课程列表通过批量摘要查询读取名称、状态、范围和章节数，不读取章节正文、关联题目详情及未使用的封面；完整内容在打开编辑页时加载。普通题当前版本、AC、正式活动成绩和试卷引用语义保持不变。
