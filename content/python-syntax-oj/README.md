# Python 语法与综合实践

这是一门独立于旧版“Python 从入门到独立解题”的课程，由提供的 `python-syntax-course.html` 整理而成。

- `course.md`：20 章课程正文，使用 `codemaster-learning-path` v1 导入格式；章节中不包含原网页的习题参考答案。
- `problems.json`：19 道章节练习及 3 道综合练习，共 22 道通用题库 JSON 题目。每题采用标准输入输出，包含 2 个公开样例和 5 个加权正式测试。`chapterNumber` / `chapterTitle` 只供导入时匹配章节，不属于题目的运行数据。

原网页中依赖随机数、磁盘文件或预设常量的练习已改成确定输入；集合、排序、舍入、错误处理与并列名次均写明了可判题规则。类、装饰器、生成器和 lambda 等内部实现方式不能仅凭标准输出判断，题面将其作为推荐练习方法，判题只检查结果。

在本地运行 `node scripts/import-python-syntax-course.mjs --check` 会检查课程结构和全部参考输出；使用 `--import` 则在保留现有数据的本地安装中建立课程和题目草稿，等待隔离判题服务完成参考解验证，再将 22 道草稿题按章节关联，供教师完整审阅。此命令不会发布课程、公开题目或修改已有课程。课程正式面向学生开放前，仍需教师发布题目、管理员审核校内公开，并发布课程。
