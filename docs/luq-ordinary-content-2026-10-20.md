# 普通题英文展示、中文翻译与参考题解（2026-10-20）

本轮范围是本地 3000 的 80 道普通题目，以及其中两题另有的 4 个已发布历史版本，共 84 个版本。公开题面使用经审核的英文展示，中文题面通过 `FULL_TRANSLATION / zh-CN` 提供，完整题解通过 `FULL_SOLUTION` 提供。沿用现有 Luq 价格、购买权益、内容提供记录和活动限制；不更新 rslab 或 3002，不提交或推送代码。

**实施状态：本地 3000 已应用迁移 047、更新 API/Web 并完成审核发布。80 道当前普通题解全部已发布，待审核和缺少内容均为 0；另补齐 4 个历史版本。未推送、未部署 rslab 或 3002。**

本次问题来自源数据：80 个当前版本中，44 个原始 `statement` 已经是中文，并非前端临时翻译。修复同时处理公开正文和公开说明字段，使界面语言不再决定是否能取得中文正文；原本为英文的 36 个版本保留英文原文。

## 内容范围与审核

| 内容 | 本轮范围 | 处理方式 |
| --- | --- | --- |
| 普通题公开英文展示 | 80 题当前版本＋4 个历史版本，共 84 份 | 原本为英文的题面保留原文；中文原题准确翻译为英文，同时整理学生可见的公开元属性 |
| 中文完整题面 | 80 题当前版本（含原 Python 课程 22 题）＋4 个历史版本，共 84 份 | 保留原题结构、变量、函数名、代码、输入输出、约束和公开说明；按准确版本保存、审核发布 |
| 新增完整题解 | 当前版本缺失的 58 份＋4 个历史版本，共 62 份 | 逐题整理中文思路、完整 Python 参考代码、易错点和适用的复杂度说明，再保存草稿并审核发布 |
| 已发布的课程题解 | 22 题 | 保留既有正文、内容 ID、审核记录和发布时间，不覆盖、不重复发布 |

整理材料只包含公开题面、公开样例、学生可见元属性，以及本次明确授权用于整理题解的现有参考程序。教师私有批注、隐藏测试、判题驱动不进入翻译、公开英文或题解。题解可以解释算法与边界，但不能把私有验证材料作为购买内容。

中文原题本身可作为中文翻译内容；对应英文展示独立保存，不能仅改题干而留下公开元属性中的中文原文。公开元属性采用明确字段清单：`objective`、`inputDescription`、`outputDescription`、`returnType`、`parameters` 和 `difficulty`。参数名称、类型和既有难度保持原意；参数说明等学生阅读字段按展示语言处理。导入元数据中的任意附加字段不会因此成为公开内容。

补充的历史内容是 Row Sums 与欢迎语各两个版本，其中两个版本仍被现有课程引用。每版都重新核对源题面、接口和参考程序，按原版本保存，不把课程链接迁到新版本。欢迎语两版的公开题意及参考代码与当前版本一致；Row Sums 历史版不包含当前版新增的公式，其中一版原有的 `k_i` 文本原样保留，不擅自推断其含义或改变函数参数。历史补齐不增加稳定题目数量，也不产生新一轮付费权益或首次 AC 资格。

两处分开记录的参考程序审阅：

- **Workshop Check-in Report**：原程序的输出行为正确，但没有将记录解析、最早到达者选择和迟到统计分别放入命名函数。题解中的代码按原题要求等价拆分为 `parse_records`、`earliest_code`、`count_late` 和 `main`，保留严格小于、严格大于、同最早时间取首条及空输入 `EMPTY 0` 的行为。原数据库参考程序不修改；原程序与题解代码分别留存摘要。
- **Import a damaged sales file / Decimal 审计**：发现原参考程序依赖默认 28 位精度，合法长整数金额可能被舍入。仅题解代码使用 `localcontext`，按本笔乘积和累计金额位数设置足够精度并提高正指数上限；原字段解析、验证、文件读写及数据库参考程序保持不变，另记录改写后代码摘要。隔离 GoJudge 已验证 2 个公开样例与 6 个独立边界，8/8 AC；原参考程序在发现的精度边界上重现 WA。该检查覆盖此题的审计修订，不代表整批发布或全部测试已完成。

内容清单保存题目 ID、准确版本 ID、原题摘要、原参考程序摘要、整理正文、审核说明与代码改写说明。分片整理后进行交叉复核；所有题解代码的实际运行由隔离判题环境完成，不在 API/Web 进程中执行。

## 版本绑定的公开英文展示

新增迁移 `047_problem_public_statements.sql` 和 `problem_public_statements` 表。每个不可变题目版本至多对应一份已审核英文展示，保存英文正文、白名单元属性、原始内容摘要、展示内容摘要、作者、审核人和发布时间。表禁止更新或删除；迁移只建结构，不自动翻译或回填任何题目。

公开展示不覆盖 `problem_versions.statement`、原元数据、参考程序或测试，不新建判题版本，也不改写课程章节与活动固定的版本引用。学生读取相同版本时采用其英文展示；教师维护及判题继续使用原版本材料。已有访问控制仍先判断题目与活动权限，新增展示记录不会把私有题目变成全校公开题。

对已经采用独立英文展示的稳定题目，学生请求未覆盖版本时只得到英文待审核说明，公开说明字段清空，返回 `publicStatementPending: true`，不能退回旧中文原文绕过翻译入口；教师仍可按管理权限读取原始草稿。此限制与历史版本补齐均已验证，原课程引用继续使用各自已审核的版本。

教师/管理员通过受鉴权的 `GET /api/v1/luq/public-statements` 读取准确版本及原始快照摘要，通过 `POST /api/v1/luq/public-statements` 明确审核后发布。请求携带题目 ID、版本 ID、`language: "en"`、正文、公开元属性、`sourceHash` 和 `reviewed: true`。服务端校验管理权限、原版本已发布、原文与公开元属性快照未变化，并使用版本锁保证并发一致性。

同版本、相同内容的重试返回已有记录；不同正文不能覆盖已发布展示，须新建题目版本并重新审核。此接口用于公开题面展示，不能提交中文翻译、完整答案、隐藏测试或私有批注。

## Luq 解锁与数据保护

中文翻译和完整题解继续使用既有受控内容接口与按版本审核流程。批量定价、内容发布、学生购买和正文提供是独立动作：没有已发布内容时不收费；发布内容不修改价格或学生余额；翻译不影响首次 AC Luq，答案提供仍按服务端记录和提交时快照影响奖励资格。

不得因切换到英文展示重新创建稳定题目、重算首次 AC 或丢失已购买权益。原 22 份题解不变，原课程关联、学生代码、正式提交、成绩、排行榜积分、Luq 流水与余额均保留。答案入口及代码主题选择沿用现有界面，默认 GitHub Dark。考核禁用、开放时间和权限检查仍优先于余额及永久权益，不能从普通题、课程或历史版本入口绕过。

发布前应保留一致性数据库备份，并核对业务表摘要；发布后分别核对 84 份英文展示、84 份翻译、62 份新增题解与原有 22 份题解，同时区分 80 个当前版本和 4 个历史版本。审核材料和数据库备份保存在被忽略的 `.campus-local/luq-ordinary-content-20261020/`，不加入源码或学生可下载资产。

## 迁移与部署口径

1. 备份本地数据库并保留现有卷；不重置账号、密码、身份、课程、活动、代码或成绩。
2. 应用迁移 047，并运行同版本的 `packages/domain/grants.mjs`。应用角色只获得所需的读取/插入权限，不能修改或删除公开展示记录；worker 不获得该表或辅助正文的新权限。
3. 使用匹配的 API/Web 版本更新本地 3000。内容发布通过受鉴权、可审计的业务接口执行，不能通过改写原题版本或余额来完成。
4. 核对普通题与课程入口的英文展示、中文翻译报价与解锁、题解查看和代码主题；保留真实学生的代码和奖励状态，扣费与答案提供的交互验证使用独立 QA 身份或独立测试环境。
5. 核对未授权响应、SSR/预加载和公共元属性均不携带未解锁中文正文、完整答案、隐藏测试或教师私有材料。

公开展示是追加式记录，回滚旧应用不能通过删除该表或改回学生数据完成。是否回退应用还需评估旧版本会否重新展示原中文题面或恢复不受保护的内容入口。

## 保留的边界

- 新版题目需要按准确版本重新审核英文展示及辅助内容；缺稿时显示待审核说明，不继承其他版本的正文。
- 之前已经由旧接口提供、保存在浏览器内存中的中文无法撤回；刷新或重新进入页面后使用本轮受控接口。教师/管理员按既有维护权限仍能读取原始材料。
- Workshop 和 Decimal 修订仅用于本次公开题解，原不可变判题版本与参考程序保留。公开样例和已列边界的通过不代替对所有可能输入的形式化证明。
