# 逐用例运行反馈与错误定位

日期：2026-11-04。范围：普通题答题工作区、提交详情及其判题反馈接口。按用户提供的 LeetCode 截图改进结果阅读流程，继续使用本站布局、配色、编辑器与 Vim 设置。Paper 4 保留原阶段结果界面，本次执行了其沙箱回归。

## 学生体验

- 样例运行、自定义运行自动打开「测试结果」，突出显示通过、答案错误、运行错误、编译错误、超时、内存或输出超限；等待及判题状态单独展示，不把上一次结果显示成新结果。
- 默认打开首个失败用例；用例标签含状态图标，支持鼠标、方向键、Home/End。公开样例逐项显示输入、实际输出、预期结果，字符差异可开关；差异中的空格、换行可辨认。
- 函数返回值和调试打印分别展示。自定义运行没有标准答案时不伪造预期结果；异常导致未返回时不显示成正常返回的 JSON `null`。
- 错误详情保留学生异常类型和有效源码位置，过滤框架调用栈。Python 语法/运行错误、JavaScript 运行栈和 C++ 编译错误可定位时，点击文件行号跳到代码；JavaScript 函数包装行号映射回学生代码。
- 定位不修改代码、草稿或撤销历史。运行后编辑过代码或切换语言会禁用旧位置跳转，提示重新运行；Vim 状态和深浅主题继续可用。

## 权限和数据边界

`packages/domain/src/submission-feedback.mjs` 统一投影私有判题结果。只有 `samples` 和 `custom` 返回公开用例详情，样例按该次提交的固定题目版本匹配。正式及订正提交仅返回用例状态、用时和内存，教师入口也不会得到隐藏输入、预期答案或原始异常输出。未公布的限时成绩不返回用例详情；待确认重判不能覆盖当前结果展示。

执行仍在隔离判题器内，应用与 worker 数据库角色分离，执行器不访问数据库。接口先执行现有鉴权；新投影使用字段白名单、长度限制和纯文本渲染，不返回参考答案、教师批注或内部用例 ID。不改评分、积分、Luq、学生代码或历史记录，无新增迁移。

限制：旧记录若未保存详细异常，需要重新运行才能获得新诊断；没有可靠源码位置的错误不提供猜测的跳转。C++ 运行异常可以显示原因，但并非总有源码行号。较大输出采用有界差异计算，截断结果有提示。
