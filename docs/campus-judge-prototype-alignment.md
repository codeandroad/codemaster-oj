# 原型与生产实现逐页对齐

基准：相邻的独立 `../myoj-prototype/` 原型、其 `docs/campus-judge-final-design.md`、用户提供的六张管理员截图。生产源码位于本仓库根目录；原型文件与 Git 状态保持原样。本记录的逐页验收发生于迁移之前，当前检查另行记录。

## 本次发现的问题

- 管理员账号列表被改成角色编辑卡片，缺少搜索、筛选、关联班级、最后登录和详情抽屉；身份列表混入班级维护，未沿用学生／教师页签。
- 三种角色的侧栏顺序均与原型不一致；品牌区域、上下文栏、页面间距及表格结构也有差异。
- 教师作业、题目、学习、训练编辑任务被简化为内联表单，缺少原型的页签、题目选择器、可视化测试用例和进度抽屉。
- 学生学习内容未分成独立章节页；答题工作区、提交与订正详情缺少原型的信息层次。
- 系统设置仅列出只读参数，没有站点配置持久化、备份计划和审计筛选；判题服务仅列队列数字，没有真实节点和维护操作。

此次还发现作业列表响应缺少参与者导致错误页、移动端工作区与提交详情溢出、笔记作者识别及旧详情查询范围、较早教师账号恢复遗漏资料等缺口，均补充相应实现与回归验证。长期使用时，自测可能挤出最近 200 条中的正式记录；现改为正式历史的服务端筛选与签名游标分页，题库状态与最高分从完整正式历史计算。ZIP 题包识别和三组／停用测试的保存权重也纳入本次流程验收。

此前验证了生产 API 与判题链路，但没有完成逐页视觉验收。历史“按原型布局完成”的表述不能作为此次对齐依据。

## 对齐原则

沿用原型的浅灰背景、白色表格与面板、蓝色操作、字号、页面宽度、管理员／教师 236px 和学生 224px 侧栏、36px 顶栏、64px 上下文栏。侧栏顺序逐项沿用原型；管理员额外保留 Dashboard 入口。

原型的“Prototype／演示数据／预览场景”控件替换为真实角色与运行状态。原型的预览成功提示替换为真实请求结果。表格行数、时间、统计、班级、节点和成绩来自数据库或 worker 心跳，不复制演示记录。隐藏测试、未发布训练结果和平台错误仍遵守生产访问与评分规则。

## 生产语义的必要区别

已有账号关联必须先明确解除旧身份绑定。跨身份关联只转移登录凭据，原身份的历史成绩、笔记作者、审计和教学内容保持原归属；目标身份只获得相应学生／教师角色，不继承来源管理员权限或邮箱。同身份重新认领／恢复可接回教学内容，包括学习资料。最后一个有效管理员不可被禁用、解绑或移除管理角色。激活码与重置凭据只在生成结果中短暂展示，数据库保存哈希或受限重放密文。

已发布题目与活动成绩保留版本快照。作业草稿可修改后发布；计时开始、截止、延期、结束与成绩发布以服务器状态为准。基础设施错误不等同于 WA，不记 0 分。重试与重判、重判候选确认与训练成绩发布是不同动作。

备份页保存真实备份计划元数据并列出已记录的备份证据。实际创建备份、定时执行、恢复到隔离数据库由服务器脚本完成；界面不执行任意宿主机命令，也不把计划保存称为已完成备份或恢复。

本轮验收已完成，本地入口为 `http://127.0.0.1:3000/login`。详细证据见 [机器可读验收记录](campus-judge-prototype-alignment-verification.json)、[教师逐页记录](teacher-alignment.md) 和 [学生逐页记录](student-alignment.md)。

- 原型 169 个受版本控制文件的内容哈希、Git HEAD 与干净状态均与分离时基线一致；生产独立源码检查通过。
- 最新 Next/Nest Docker 生产构建、Web/API TypeScript 与 Web ESLint `--max-warnings 0` 通过。
- 80 项领域集成测试、1 项真实 Nest HTTP 综合测试、18 项 ZIP/YAML/权重回归全部通过，没有失败或跳过。领域测试使用实际 PostgreSQL 与 Linux go-judge。
- 最终生产服务上的 Chromium 检查覆盖 45 个角色页面／页签状态的 1440px 和 390px 视口，以及 390px 登录／注册，共 92 项；页面异常与文档横向溢出均为 0。管理员截图所示的表格、导入步骤、身份页签、节点与维护面板、四页签设置，以及教师编辑器和学生工作区已对照原型检查。
- 完全隔离数据库中的 17 组跨角色可写流程通过：身份建档认领、账号启停／角色／密码恢复、设置与维护、建班、题目编辑验证发布、作业、学习、正式提交、独立订正、训练开始／结束／成绩发布、跨身份凭据关联与审计。
- 另 5 组隔离专项通过：无 JSON／无 PID 的双题 ZIP 实际导入、三点精确权重保存、三启用一停用正式测试、公开样例名称／启用状态持久化与真实 Run Samples、正式历史分页与旧订正详情。启用权重为 `33.3334 / 33.3333 / 33.3333`，错误的停用样例不参与参考解或学生样例执行。分页用 53 条正式和 205 条自测合成历史验证；合成历史只用于分页，参考解与样例均经过实际执行器。
- 学生只读专项验证全部 11 种状态、4 种来源及实际题目筛选、真实游标、活动来源隔离和手机详情；原 WA／75 与独立订正 100 保持分开。
