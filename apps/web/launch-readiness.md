本文件保留 2026-10-13 的上线检查记录。当前仓库直接在根目录维护生产源码；正式部署和首次管理员初始化以项目根 [部署说明](../../docs/campus-judge-deployment.md) 为准。下文的“单文件更新包”描述仅为当时的交付记录，当前仓库没有 `apply-production-style.mjs`。

## 当前结论

本次清除了教师页面设计编号和主导航固定示例课程名称，新增真实用户账户菜单（设置、可用角色切换、退出）。教学内容预览、作业预览、主题配色预览是正式功能，予以保留。RECON 测试数据与旧原型不属于生产构建。

当前不能宣称已经完成上线验收：本会话没有对真实部署的 PostgreSQL、HTTPS、判题容器、备份恢复和并发容量进行端到端验证。应先在预生产环境完成下列检查，再开放学生访问。

## 部署配置核对（基于实际 deploy 源码）

- deploy/compose.yaml 对 APP_ORIGIN、各数据库密码、SESSION_SECRET、JUDGE_AUTH_TOKEN 强制要求非空，但不会自动拒绝 .env.example 的占位文本。必须分别生成随机值；不要使用示例密码。
- CAMPUS_HOST 与 APP_ORIGIN 应指向同一正式 HTTPS 域名；DNS、80/443、防火墙及 Caddy 证书签发必须实际验证。正式配置 COOKIE_SECURE=true，勿以 HTTP 测试其登录。
- 数据库无宿主端口，API、worker 分别使用 campus_app / campus_worker；migrate 使用 campus_migrator。迁移和授权必须成功后再启 API/worker。
- judge 使用 privileged=true，且运行于 execution 内部网络，无宿主端口、Docker socket 或业务卷。该隔离是配置意图，仍须在专用 Linux 主机验证 cgroup/namespace、网络禁止、超时、内存限制与恶意程序终止。不要直接与其他重要业务共宿主。
- compose 中没有自动备份、恢复演练、业务告警与容量测试流程。上线前需补齐数据库定时备份及异机副本、恢复演练、队列/判题失败/磁盘告警；30–50 并发只是配置备注，并非实测保证。
- Debug 隔离调试服务尚未接入，不属于可上线承诺；不能将禁用入口视为可用调试能力。
- 需实际核验登录/CSRF、权限越权、密码重置、导入、草稿恢复、活动发布与结束、Python/C++/JavaScript 判题、重启后数据持久化。依赖漏洞扫描需要在部署时联网运行，当前文档不声称漏洞扫描通过。

## 创建第一个管理员

没有默认管理员账号/密码，也不应配置公共注册自动成为管理员。bootstrap.mjs 使用事务与 advisory lock；已存在 admin 时会拒绝再次 bootstrap，后续管理员应通过邀请流程创建。

先按项目根 [部署说明](../../docs/campus-judge-deployment.md#首次部署) 配置私有 `deploy/.env`、完成迁移，再用迁移服务的交互式 bootstrap 创建管理员；它复用服务已有的迁移数据库凭据，不需要将密码写入命令行。随后启动业务服务，以 HTTPS 登录核对管理员角色和审计记录。已有管理员时请使用邀请，不删除角色绕过初始化保护。

## 角色权限显示

管理员包含教学权限：账号列表、角色筛选和「角色与范围」均显示有效 teacher 权限；admin 勾选时 teacher 自动勾选并标注「管理员包含」，不可单独取消。取消 admin 后仅保留显式授予的 teacher；继承显示不会向数据库额外写入 teacher，也不会提升普通教师权限。

## 运行环境语言显示

运行环境表不再写死 C++ 未配置：Python、C++、JavaScript 的版本与关联节点由 worker 环境探测字符串解析，节点心跳决定可用状态；无观测时显示未获取。Java 镜像与编译判题尚未接入，明确显示当前不支持，不冒充已配置。

## 班级创建与公共页面整理

管理员创建班级不再被强行作为显式教师提交；后端负责教师查询接受具备管理员继承教学权限的账号，保持权限模型一致。运行环境只列 Python/C++/JavaScript，未接入 Java 不显示。公共页面标题、描述宽度、状态色、表格行高与表单圆角统一，并保持既有主题色。

CodeMaster OJ 字标更新为现代无衬线矢量轮廓，保留书页与代码括号符号。BrandLogo 统一使用本地透明 SVG，主题上下文选择浅色/深色版；登录、侧栏与调用该组件的工作区同步更新。浏览器 icon.svg 改为独立符号。新资源包含在单文件更新包内，无额外字体与网络依赖。

## 编辑页题目列表抽屉

代码编辑页左上「题目列表」打开左侧模态抽屉，展示 API 返回的可访问题目，支持标题搜索、当前题目、加载/空列表/错误重试状态。选择其他题目使用既有 navigateWorkspace 草稿离开保护，进入独立题库练习，不继承作业或计时训练上下文；原上下文返回入口保留。Esc、遮罩及关闭按钮可关闭抽屉，焦点由模态组件管理。

## 编辑页账户与通知

代码编辑页顶部右侧增加真实账户头像（设置、角色切换、退出），退出有未提交草稿确认并调用 auth/logout。通知改为铃铛锚定下拉面板，学生主页面共用该组件；展示真实站点公告和作业截止提醒，支持加载、空状态、失败重试、Esc/外部点击关闭。现有服务未提供独立未读/已读接口，因此不伪造未读计数或已读操作。LeetCode 登录后的通知面板无法通过公开页面获取，本轮采用通用铃铛下拉交互，不宣称像素级复刻。
