## 整理与审核边界

材料只选择这 115 道本站原创练习的公开英文题面、两个公开样例和本次明确授权的参考程序。没有从 HackerRank 转载答案，也没有选择正式测试、判题驱动、私有元属性或教师批注。

- 中文题面保留任务、接口、说明、公开样例的结构；逐项翻译约束、输出格式、符号和返回类型，保留函数名、变量名、命令名、格式字面量及 JSON 样例。公开样例仅规范化末尾换行，不改输入输出内容。
- 题解包含逐题中文思路、易错点、适用的复杂度说明和完整 Python 参考代码。代码与原已验证参考程序一致；函数题仍由系统调用 `solve(data)`，不增加 main 或 main guard 要求。
- 每项正文都有稳定题目 ID、准确版本 ID、源题面摘要、参考代码摘要及整理正文摘要。公开正文生成路径没有读取正式测试字段。
- 先保存为内容草稿，再通过管理员审核。115 份题解使用既有带内容快照与幂等请求号的批量审核接口；115 份译文通过既有单项审核接口发布并逐项核对正文。没有直接写库绕过审核。
- 遇到已有同类型内容时核对完整正文；不同正文或撤回内容会停止，不覆盖他人内容。已有已发布内容不能原地替换，修订仍需按既有准确版本流程处理。

完整内容与审核回执保存在 Git 忽略的 `.campus-local/hackerrank-python-course/luq-content/`，不放入网站公开资产目录。

## 代码主题与本地界面更新

核查发现，原有主题选择只覆盖 Paper 4 题解和教师预览，普通题学生答案使用通用代码块、没有主题下拉框。本次抽出共用 `SolutionContent`，由普通题的已提供答案、Paper 4 题解和教师预览共用，默认 **GitHub Dark**，保留现有 14 个代码主题及 Paper 4 的复制动作。

控件使用现有 `editor-themes.ts` 令牌、CodeBlock、MathContent 与 locale provider；可访问名称为「参考代码主题 / Reference code theme」。选择主题只改变局部展示状态，不查询正文、不新增提供记录、不改变扣费、代码草稿或未保存状态。受控正文仅在原有鉴权提供或教师预览之后传入组件；翻译展示沿用原有内容组件。

仅重建并更新本地 web 容器，未重建 API、worker、执行器或数据库。本轮没有 SQL 迁移。新增 DESIGN.md 记录现有紧凑布局、原生选择器、主题令牌来源及共用组件所有权；没有全站换肤。

## 数据保留与限制

发布前保存一致性 PostgreSQL 备份。发布后比对 23 张受保护业务表的条数和逐行聚合摘要，全部相同，包括原题/版本/测试、课程/章节/关联、学生代码与成绩、Paper 4 记录、积分、Luq 账户/流水/权益/提供记录/规则/设置版本。原有 360 份辅助内容整行一致，辅助内容总数仅追加到 590；未给学生创建测试购买或答案提供记录。

新增审核批次及审计记录属于本轮授权操作。正文及题解开放仍服从原有权限、活动限制、开放时间、购买权益与答案提供快照规则；本轮不改变规则。真实学生没有用于端到端扣费测试，相关扣费和提供行为通过独立数据库集成测试核验；主题浏览器核验使用合成代码夹具，不能冒充真实学生已购买答案的记录。

现有 Next.js 版本在构建时仍报告安全公告，需单独核实和升级回归；本轮未扩展到依赖升级。静态审计中的 17 项既有表单问题也未扩大范围改动。未进行手机实机或屏幕阅读器认证；窄容器测试不等同于完整设备兼容性验证。
