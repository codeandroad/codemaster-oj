# ACSL Intermediate C4 数字电路教程

2026-11-12。数字电路作为第十一个专题加入原统一课程，新增三节双语课、十二道原创自测及逐步解析、十二道固定版本真题关联。累计十一专题、36 课时、120 道真题关联。此专题独立验收和提交，下一专题为汇编语言。

## 教学内容

| 课时 | 内容 | 关联真题 |
| --- | --- | --- |
| 1 | AND、OR、NOT、NAND、NOR、XOR 的门符号；反相圆点与连接点；命名中间信号、逐门求值 | 1 道 |
| 2 | 完整真值表、独立输入与共享信号、TRUE/FALSE 计数、输入限制及不相交分类 | 7 道 |
| 3 | 绑输入 NAND、德摩根等价、全域证明与反例、从目标输出反推输入 | 4 道 |

依据 [ACSL Digital Electronics](https://www.categories.acsl.org/wiki/index.php?title=Digital_Electronics) 和六年 Intermediate C4 十二道电路题核定范围。先写每个门的直接输入与输出，再合并布尔式；反相横线覆盖完整门结果。共享输入始终代表同一个变量，不能把依赖的内部信号当成独立输入计数。原创自测解析与正式真题解锁相互独立。

四幅原生图分别为六门符号图、NOT–AND–OR 逐门电路、共享 B 的 OR–NAND–XOR 电路，以及两级绑输入 NAND 等价电路。图中反相为空心圆、连接为实心点，刻意避开无标记线交叉。图形附完整等价方程和双语替代说明，支持现有 SVG 放大及 Markdown 编辑导出。

内容校验从实际 polyline 连通分量重建门输入，核对门形、反相、连接点和命名信号，再穷举输入与显示真值表比对。独立交叉复核另重算全部自测、约束计数、德摩根变换和逆推分类，未发现算理或翻译不一致。
