## 目录、语言和进度

- 课程目录显示 C1–C4 分组标题；专题可折叠，当前课时所属专题默认展开，专题显示已读课时数与总课时数。

- 课程、专题、分组和课时支持中英文内容。切换语言只改变显示，不产生另一套章节或阅读进度。界面语言与内容语言继续独立。

- Markdown 的 YAML 头部可选 `sections`，课时可选 `### 所属专题`。旧文件不需要增加字段；导入导出继续保留双语正文、自测和固定版本练习引用。

“已读”仍是主动阅读记录，不等于掌握，也不发积分。课程总进度和专题计数不重算正式答卷。原创自测答案主动展开；真题答案、解析和成绩继续由原 ACSL 权限与交卷规则控制，课程链接不能提前解锁。

## 旧草稿如何合并

本次工具针对天行创世纪学校现有的六门双语专题草稿。保留原数制课程作为主课程，将另外五门的课时迁入同一课程并赋予专题标识：

1. **保留身份与记录**：保留主课程 ID 和全部原课时 ID；正文、译文、自测、固定题目版本及阅读记录沿用原数据。不是删除后重新导入课时。
2. **同步迁移资料**：关联课程或课时的学习资料迁到主课程；课时对应关系保持不变，原来已归档的课时仍为归档状态。
3. **保留旧入口**：其余五门来源草稿归档并保存到主课程的别名映射。教师和学生旧链接解析到主课程；有明确课时就保留该定位，没有课时则进入原专题的首课。语言、预览、筛选和返回上下文保留。合并来源不能通过“恢复”成为另一门可编辑课程。
4. **保留权限边界**：别名按主课程重新检查访问权限。主课程未发布时，学生仍不能读取，旧 URL 不构成例外。脚本不会发布课程或扩大班级准入范围。
5. **一次提交变更**：服务端锁定并核对课程、课时和资料，在一个数据库事务中完成归属调整、来源归档、别名、审计与合并回执。保存合并前快照供核查；快照不等同于自动回滚功能。

服务端只接受同校、同一教师、尚未发布且未归档的草稿。来源的准入、班级、开放时间、语言要求及难度等须一致；已有作业、限时练习、公开发布历史、生成配套练习或其他合并别名的课程不进入本次自动合并。脚本还逐门比对编写源，教师改过的内容、同名重复草稿、缺少或已改名的专题都要求先核对，不覆盖编辑。

执行前取得服务端预览哈希；真正执行时重新校验。预览后资料或课程发生变化会拒绝执行，不提交部分迁移。相同计划重试使用原回执，避免重复迁移。新增数据库结构采用增量迁移，不能通过重置数据库、种子账号或清空进度完成整合。

历史 [C1 扩写记录](acsl-tutorial-c1-expansion.md) 和 [C2 扩写记录](acsl-tutorial-c2-expansion.md) 中的独立课程链接保留，作为当时的验收证据；在目标环境完成本轮合并后，旧链接转到统一课程内相应专题。早期单语言样板的历史归档也保留，不混入本次六门双语草稿的合并。

## 本地工具使用

以下命令在仓库根目录运行。先校验编写源和统一文档，均不连接业务 API：

```sh
node scripts/check-acsl-tutorials.mjs --all
node scripts/import-acsl-course.mjs
```

全新本地环境由平台管理员导入；已有平台统一课程时，命令核对内容并承接原课程及课时，不另建副本：

```sh
node scripts/import-acsl-course.mjs --import --origin http://localhost:3004 --auth-file PRIVATE_PLATFORM_AUTH_JSON
```

历史学校合并脚本 `merge-acsl-tutorials.mjs` 已停止写入。原合并回执、日志和五个别名保留；其他环境如尚有学校来源草稿，须先执行经过核对的数据迁移，不能删除重建。3004 现有统一草稿由定点增量迁移转交平台，保留原 39 课时和 128 项固定版本关联。

导入与追加只接受明确端口的本机 HTTP 地址，要求有效的平台管理员身份并调用平台课程 API。私有认证文件位于忽略目录，包含 `username`、`password`；不得把值写入版本库、文档或命令行参数。学校教师或校管身份会在课程写入前被拒绝。

新的平台维护日志位于 `.campus-local/acsl-tutorial-import/`，按本地环境隔离，不因操作管理员更换而另建课程。原教师日志保留作历史核对。遇到同名但不同内容、已发布、已归档或已编辑的课程，脚本拒绝覆盖。创建使用固定请求 ID 支持重试；课程初始仍是天行试点范围的草稿，不自动发布。

后续追加先核对旧课程内容、专题顺序、课时 ID 与固定题目版本，再以 `revision + sourceVersion` 保护的单次事务追加；并发修改会拒绝整个写入。响应丢失时重新读取和核对，不盲目重复新增：

```sh
node scripts/extend-acsl-course.mjs --origin http://localhost:3004 --auth-file PRIVATE_PLATFORM_AUTH_JSON
node scripts/extend-acsl-course.mjs --apply --origin http://localhost:3004 --auth-file PRIVATE_PLATFORM_AUTH_JSON
```

只校验本地源文件时直接运行以上脚本而不提供认证参数即可；不会连接业务 API 或产生维护日志。
