# 教师工作区原型对齐记录

本记录对应相邻原型的 `../myoj-prototype/docs/campus-judge-final-design.md` 第 5、7、8、9 节及原型教师页面。原型文件保持只读；生产教师组件位于 `apps/web/src/components/teacher/`，通过独立生产 API 工作，没有导入原型源码、配置、资源或演示数据。

## 原型展示与生产规则

- 原型的外观、页面顺序、表格列、页签、选择器、抽屉和上下文导航保留。顶栏角色切换与演示数据工具条替换为真实角色及授权工作区入口。
- 固定示例人数、分数、导入结果与节点状态全部来自真实数据。生产不会通过控件切换虚构判题状态。
- 公开样例不计正式分。隐藏测试和教师参考解仅授权编辑者读取。提示采用服务端 `always` / `afterAC` / `never` 策略，在计时训练反馈未开放时仍遵守服务端限制。
- 原成绩、订正结果、重判候选和已发布训练成绩快照分别呈现。Waiting/Judging/System Error 保留其含义，不在前端换算成学生 WA 或 0 分。
- 时间报告明确为“活动创建时间”，不将该筛选描述为历史成绩重建。
- 保存失败显示真实错误；表单不报告虚构成功。题目、作业、章节、训练草稿的未保存修改提供原生离页提醒。
- ZIP 内容仅在浏览器读取，校验文件数、展开大小、路径和长度；不执行包内代码或解压到服务器目录。

## 当前验证证据

- 当前教师源码通过 Next/TypeScript `tsc --noEmit` 和完整 web ESLint（`--max-warnings 0`）。
- 对较早生产构建完成 18 个教师页面的无头浏览器读取与截图，以及作业原提交/订正抽屉、视觉用例抽屉检查。该轮发现作业列表旧响应缺少参与者导致页面错误，已补空值防御并由后端返回完整列表合同。
- 本轮部署重建后重新检查 19 个教师路由（增加题库详情）及上述两个抽屉，共 21 项读取/弹窗检查；没有浏览器页面错误、错误边界或非空警告。已视觉检查题库详情、作业列表、训练编辑页截图。
- 该轮读取检查后又补齐题库行内“编辑测试”、分组标签入口和作业适用人数分母；这些变更通过完整 TypeScript/ESLint，并已部署到本机生产服务。
- 独立数据库、受限 Nest API/worker 与真实 Python 执行器的浏览器验收通过 17 组跨角色可写流程；教师侧包括选学生建班、统一题目编辑与测试抽屉、参考解验证后发布、五页签作业保存后发布、学习正文/检查点/题目引用保存发布、资料发布、计时训练与独立成绩发布。已有演示数据未用于可写测试。
- 常规验收保留已有学生成绩、个人训练尝试、账户和密码。可写流程须使用明确的新建 QA 草稿或完全隔离数据库。

## 标准 ZIP 题包兼容补齐

生产导入现支持 `problem.md` 题包，根目录或多个子目录各对应一道题；配置和外部 `pid` 均可省略。默认题名按非空配置标题、题面一级标题、目录名、ZIP 文件名依次选择。题面样例代码块或 `samples/` 文件构成公开样例；`tests/`、`testdata/` 的 `.in/.out` 按完整文件路径配对构成正式测试。一个输入文件包含 103 组输入仍只算一个测试点。样例文件不会重复计为正式测试。

可选 `config.json`、`config.yaml`、`config.yml` 支持标题、时限、内存、接口、样例与测试文件引用、参考解/模板引用及来源信息；YAML 配置可放在题包根目录或 `tests/`、`testdata/`。`reference.py`、`solution.py` 可提供教师参考解，`starter.py` 可提供学生模板。缺少参考解、样例、正式测试及未配对文件会在候选中明确提示；可以保存待完善草稿，真实参考解验证通过后才允许发布。原有 JSON 文件及 JSON 清单 ZIP 继续支持。题包中的 owner、pid、历史提交统计仅作来源信息或忽略，不创建账户、改权限、覆盖内部题号或导入历史成绩。

浏览器 ZIP 解析限制压缩文件 2 MB、解压合计 2 MB、最多 512 项，校验本地头与目录、长度及 CRC；拒绝重复/大小写冲突路径、路径穿越、反斜杠路径、符号链接、加密文件、分卷、ZIP64、过高压缩比及非 stored/deflate 压缩。只有需要的题面/配置/代码/测试文本按 UTF-8 解码；代码只作为待验证文本上传，不在浏览器或 Web/API 进程执行。YAML 使用本应用锁定的 `yaml@2.9.1`，检查解析错误、未知标签、别名上限、循环与配置深度。其配置选项见 [yaml 官方文档](https://eemeli.org/yaml/)。当前平台按启用测试等权计分，不能等价表达的子任务计分配置会明确拒绝，避免静默改变源题计分。

统一编辑器与题包导入共用精确权重分配：启用测试以整数单位分配 100 分，最多四位小数，余数按顺序分配；停用测试保留正权重且不计入总和。三条启用测试与一条停用测试不会因 100/3 浮点数或停用权重为 0 而保存失败。

当轮验证命令现在应从生产仓库根目录运行：`node --test apps/web/tests/problem-package.test.mjs`。当轮 18 项回归通过，覆盖无 JSON/无配置/无 pid 的原型布局、103 组输入、无标题回退、stored/deflate、样例与正式测试分离、多题包、可选 YAML 文件引用与 source owner、JSON ZIP 兼容、空输入、未配对提示、函数配置、安全路径/符号链接/CRC/文件边界/展开限制、YAML 安全限制及三启用一停用权重。当轮全部 Web TypeScript 和 ESLint 同时通过。

最终构建的独立数据库浏览器专项另通过 5 组：双题标准 ZIP 实际导入与预览、可视用例抽屉、三点权重真实保存、补齐参考解及三启用一停用测试实际 AC、公开样例名称和启用状态保存重载、学生仅见启用样例且真实 Run Samples 得到 AC（1/1），以及正式历史分页和旧订正详情。合成历史只用于分页检查；参考解和样例调用真实 Python 执行器。临时数据库、角色与代理已清理。最新教师侧栏逐项使用原型图标，最终 92 项桌面／手机页面检查均通过；完整证据见 [本轮验收记录](campus-judge-prototype-alignment-verification.json)。
