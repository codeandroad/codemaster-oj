# 资料、积分与排行榜使用说明

## 个人资料

侧栏底部的个人资料按钮已移除。顶部头像菜单提供「个人资料」「积分排行榜」，并显示当前积分。资料页可编辑昵称、个人介绍和头像；实名、学号/工号仍由管理员维护。昵称最多 40 字，介绍最多 500 字。头像支持 PNG/JPEG/WebP，在浏览器裁切压缩为 256×256 JPEG，原图最多 5 MB。头像与昵称用于菜单及排行榜。

## 积分规则

- 普通题目默认首次正式 AC 获得 10 分，以学生身份 + 题目 ID 去重。新版本、重复提交、订正、不同账号重新绑定同一身份都不能重复获取该题首次通过积分。
- 运行样例、自定义输入、教师参考解校验不计积分。只有真实正式 submit/correction AC 才会授予。
- 仅管理员可调整题目首次通过分值（0–30 分）；教师不能修改全局题目积分。
- 教师可为本人作业题目设置额外 0–20 分任务奖励，以学生身份 + 作业 + 题目去重。例：题目首次通过值 10 分，作业奖励 5 分，首次在此作业通过得 15 分；已通过该题的学生完成此作业仍可得任务奖励 5 分。
- 计时训练隐藏结果不即时授分；管理员/教师公布结果后，对正式 AC 去重授分。
- Paper 4 试卷正式交卷（包括截止自动交卷）后，系统按冻结的最终代码逐道大题运行全部自动测试。每道大题首次完整自动 AC 固定获得 10 分，计入个人累计积分及全校积分排行榜；不同班级、重复交卷、重复判题和新版试卷不重复授予同一道大题。教师人工评分和证据阶段不改变自动 AC 奖励，整卷成绩也不折算积分。交卷前的练习运行不授分；旧版历史答卷不追溯补发。
- 奖励设定只影响后续入账，已入账金额固定，不随教师修改而改变。已授积分不随重判失败自动扣除；这是学习激励账本，不是课程成绩，不用于替代考试评分。
- 积分系统启用前的历史 AC 不自动补发；启用后的有效 AC 首次计入账本。积分不能通过修改本机数据获得。

授分由数据库触发器随判题结果同一事务完成，唯一索引防止并发重复加分。Paper 4 使用独立的不可变积分流水，不生成普通 OJ 的题目或提交记录。不依赖浏览器保持打开，不影响原有判题分数、阅读进度和课程成绩。

## 教师配置

教师在头像菜单进入「排行榜与任务奖励」，选择本人作业及题目配置追加奖励；管理员另可配置全局题目首次通过分值。教师端不显示个人积分，教师身份完成题目不获得积分。建议在下发作业前完成配置，保证同一班级的授分标准一致。界面显示当前配置；保存时后端再次检查题目维护权限或作业归属。

建议普通语法练习 10 分，综合题 20–30 分，作业追加奖励 5–10 分。初始版本不设签到积分、扣分、兑换或累计连胜奖励，避免偏离练习目标。

## 排行榜

按公开普通题和 Paper 4 正式交卷大题首次完整 AC 的积分之和排名；作业、限时训练额外奖励只进入个人累计积分。榜单的「解题数」将每道取得排行榜积分的普通题或 Paper 4 大题各计为 1 题，「提交次数」将每次 Paper 4 正式交卷的大题各计为 1 次。按积分降序排列；同分时以 AC 率（有效正式提交中通过的比例）降序打破平局，使用未四舍五入的实际比例。无有效判题结果者的 AC 率记为空，排在已有 AC 率的学生之后。积分和 AC 率均相同时并列名次，并列内按稳定身份 ID 排列；这一规则在字段被管理员隐藏时仍适用。显示昵称（未填写则使用默认称呼）、头像和积分，不返回学号、邮箱或隐藏判题成绩。头像菜单中的积分在每次打开时读取。

## 安装与验证

此更新包含 015_profiles_points.sql 和 016_student_points_limits.sql。当前仓库已包含源码与迁移，无需运行旧交付包的 `apply-production-style.mjs`。备份后在生产仓库根目录执行：

```sh
docker compose --env-file deploy/.env -f deploy/compose.yaml build migrate api web
docker compose --env-file deploy/.env -f deploy/compose.yaml run --rm migrate
docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --no-deps api web
```

必须先迁移再启动新版 API；迁移保留现有账号、课程、题目和成绩。无需重新导入 Python 题目。没有连接或修改部署数据库；真实授分 SQL 已在独立 PostgreSQL 17 容器验证，页面与权限也有独立验证。

## 本次资料页与奖励限制修复

上轮安装包未包含 student/pages.tsx 的资料编辑接入，已补齐。个人资料现在使用独立 /student/profile、/teacher/profile、/admin/profile 页面，仅展示头像、昵称、介绍；账户设置改为 /student/settings、/teacher/settings，管理员系统设置仍为 /admin/settings。

每份作业追加奖励总额最多 100 分；每名学生每周追加奖励最多 200 分，按北京时间周一零点重置统计窗口。超过周上限的部分不补发，任务已经领取（含零分）不可下周重复领取。题目首次 AC 默认 10 分不计入任务周上限。设置保存时锁定作业以防并发突破预算，授分时锁定学生身份以防并发突破周上限。

016 将既有奖励配置收敛至每题上限和作业预算，不改动已授积分；未来不再为教师身份授分。安装后先执行迁移，再重建启动 API/Web。

## 限时训练实时反馈

限时训练倒计时移至代码编辑页顶部导航中心。正式提交立即显示 AC/WA/CE 等判题状态；最终分数和隐藏测试详情仍待教师发布，计时积分仍在结果发布时授予。旧 showVerdict 标志不再遮挡判题状态，教师页面相应显示固定反馈规则。此轮无数据库迁移，更新本仓库源码后重建 API/Web。
