## NumPy 执行器决策

`deploy/python-vendor-requirements.txt` 固定 NumPy 2.2.6，只安装经 SHA-256 核对的 CPython 3.12 Linux x86_64/aarch64 二进制 wheel，不构建源码或自动解析额外依赖。依赖放在镜像中 `/usr/local/lib/campus-python`，随现有 `/usr` 只读挂载；库的版权/许可证保留在 wheel 中。版本与发行文件依据 [PyPI 官方元数据](https://pypi.org/pypi/numpy/2.2.6/json)。

Python 继续使用 `-I -S`，不启用用户 site-packages、`.pth`、sitecustomize 或外部 PYTHONPATH。可信启动代码仅追加这一个固定只读路径。标准输入输出程序通过 runpy 保持 `__main__` 执行语义；函数/预检/Paper 4 驱动保留原参数协议。固定 OpenBLAS/OMP/MKL 线程数为 1，保持原进程数、CPU、内存、文件、网络和输出限制。

运行时声明包含 `numpy2.2.6` 时，接单前通过真实隔离命令检查该版本确实可导入。Compose 中 API 和 worker 使用同一新运行时标识；没有扩大数据库角色权限、执行器挂载或网络访问。生产 Compose 的声明仅随代码更新，本轮没有重建或部署线上服务。

这不是 Python 主版本升级。旧版本、题目/活动快照、判题记录保持不变；不重判学生历史提交。
