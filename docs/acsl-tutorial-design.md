# ACSL 专题教程设计

2026-11-11 制定，2026-11-12 更新实施状态。目标为 **Intermediate 优先，兼顾通用基础**。这是自主编写的备赛课程，不是 ACSL 官方课程。

## 本轮交付与后续边界

第一阶段完成完整专题结构、第一专题“计算机数制”的四节中英文样板、内容校验工具，以及既有课程模块中的隔离本地验收；当时创建了两份单语言草稿，历史记录见 [首批内容验收](acsl-tutorial-validation.md)。第二阶段已完成一门课程内中英切换、共享阅读进度、结构化 ACSL 练习关联及复盘返回入口，实施与本地验收见 [双语、进度与真题关联](acsl-tutorial-integration.md)。第二阶段当时在本地 3004 将数制中英样板合并为一门双语草稿，保留原课程与四章 ID；旧中文草稿归档保存。这是语言合并的历史状态，不代表本轮所有专题整合已部署。

第三阶段扩写递归函数和程序追踪，各三节中英文课件，与数制合计十节；内容、验收范围和草稿入口见 [C1 扩写记录](acsl-tutorial-c1-expansion.md)。第四阶段继续完成 C2 的表达式、位串运算和 LISP，各三节；累计六专题、十九节，覆盖 64 道真题，见 [C2 扩写记录](acsl-tutorial-c2-expansion.md)。其余 20 节仍待编写。试点课程保持未发布，由教师验收后再安排学生开放。

本轮按已确认方案，将上述内容组织为一门 **ACSL Intermediate 系统课程**：C1、C2 为目录分组，六个专题下设十九课时；C3、C4 的其余六专题二十课时完成后继续加入同一课程。总规划仍为十二专题三十九课时。实现、原 ID 与资料迁移、旧入口兼容及安全操作见 [统一课程说明](acsl-unified-course.md)。本轮本地验收与 3004 部署结果待主任务补记。

前述各阶段的验收文档和独立专题课程链接保留作为历史证据；目标环境完成合并后，旧链接会转到统一课程对应专题，不应据历史文档继续新建独立专题课程。

不建立第二套课程系统。复用现有课程的创建、编辑、草稿、发布、章节阅读与教师管理。天行创世纪学校继续作为首个试点，发布与内容验收分开进行。

## 教学目标

学生能说明一个操作为什么正确，独立展示中间状态，并选择一种方法核对结果。只记住选项、只读过解析或偶然做对一道题，都不足以判断已经掌握。

Intermediate 为正文深度。每节开头补充必要基础，正文完成该组别所需推导；扩展挑战单独标明，不让入门学生误以为提高内容是前置要求。课程按专题组织，学年和轮次用于安排真题练习，不逐年重复讲授概念。

## 课程地图

下列四轮主题依据 [ACSL 官方 Study Materials](https://www.acsl.org/get-started/study-materials) 于 2026-11-11 核对，并与本地 2020–2021 至 2025–2026 的 Intermediate 24 卷、128 道笔试对应。历年题数和具体范围以各份原卷为准。节数为编写计划，不代表已有课件。

| 轮次 | 专题 | 建议小节 | 学习成果 | 主要先修 |
| --- | --- | --- | --- | --- |
| C1 | 计算机数制 | 4 | 位值、合法数字、双向转换、分组转换、进位借位及混合进制检查 | 整数四则运算 |
| C1 | 递归函数 | 3 | 找基例、展开调用树、回代计算，区分嵌套调用与普通乘法 | 分支、函数记号 |
| C1 | 程序追踪 | 3 | 按执行顺序维护变量表，辨别赋值、条件、循环边界 | 变量与整数运算 |
| C2 | 前缀／中缀／后缀 | 3 | 用结构和操作数个数读表达式，转换后用求值检查 | 栈的直观模型、运算优先级 |
| C2 | 位串运算 | 3 | 保持位宽，逐步跟踪逻辑、移位与旋转 | 数制、逻辑真值 |
| C2 | LISP | 3 | 区分原子和列表，追踪 CAR/CDR/CONS 等题目规定操作 | 表达式嵌套 |
| C3 | 布尔代数 | 3 | 明确取反范围，使用恒等式与真值表交叉验证 | 逻辑运算 |
| C3 | 数据结构 | 4 | 跟踪栈、队列、树的构造与遍历，记录题目中的重复值规则 | 列表、递归基础 |
| C3 | 有限状态机与正则表达式 | 4 | 按字符跟踪状态，理解字符类、重复与完整匹配 | 集合、字符串、布尔逻辑 |
| C4 | 图论 | 3 | 将图转成邻接关系，枚举路径时遵守顶点和边的重复限制 | 集合、计数 |
| C4 | 数字电路 | 3 | 为中间连线命名，逐门求值并对照布尔式 | 布尔代数 |
| C4 | 汇编语言 | 3 | 按指令表更新寄存器、内存与程序计数器 | 程序追踪 |

预计 39 节短课。单节先按 15–30 分钟编写；包含嵌套列表和求值扩展的 LISP 课预留较多时间，再通过试点学生的实际阅读与自测耗时调整。C1 依次编写数制四节、递归三节和程序追踪三节；之后按 C2、C3、C4 扩展。原有真题主题元数据与课程单元的逐题映射保存在 `content/acsl-tutorials/curriculum.json`。

编程采用并行训练线：读懂输入输出 → 建立状态与规则 → 拆分函数和模拟过程 → 边界用例 → 判断复杂度。它使用独立练习与现有判题模块，不能把 24 道比赛编程解答直接拼成课程正文。首批数制教程不需要编写或执行学生程序。

## 一节课的教学结构

1. **学习目标与先修检查**：说明学完后能完成什么；用一个很小的任务发现缺失基础。
2. **概念与表示**：解释符号、范围与不变量。例如数位必须小于进制，位权从右侧的零次幂开始。
3. **完整例题**：显示推导的每个关键状态。加法和减法按位对齐，进位写在接收列上方；递归用调用树或回代表；栈和队列用操作前后状态；图与电路用原生图形。
4. **逐步放手**：先给完整例题，再让学生补关键一步，最后独立完成变式。自测不只换数字，也改变位数、进位次数或边界条件。
5. **错因辨析**：展示典型错误的哪一步失效，以及如何自行检查。
6. **原创自测与按需解析**：学生先推导，再主动展开答案。答案解释方法，允许合理的不同解法。
7. **回到练习**：推荐对应知识点的正式题。题号和状态可导航，答案仍由原 ACSL 权限和交卷规则控制。

例题和自测均自主编写。课程不得携带现有试卷的答案键、正式测试或参考实现；不得原样复制某道真题的完整求解过程作为公开教程。教学样板的自测答案属于原创练习，主动展开不会开启任何真题解析权益。

## 页面和学习流程

课程目录复用现有列表，阅读进度与实际练习完成情况分开呈现。ACSL 目录的“专题学习”入口仍属后续安排；第二阶段已在具体题目、复盘和编程页面提供相应教程入口，只推荐学生有权读取的已发布课程。进入教程保留原试卷、题号、复盘筛选和返回地址，返回后继续原任务。

桌面沿用左侧课程目录、右侧正文和自测；手机沿用可收起的目录。目录先显示轮次分组，再显示可折叠专题及课时；当前专题默认展开，专题分别显示已读／总课时。下一课可跨专题前进，课程总阅读进度统一统计。每页只有当前学习任务作为主要操作。公式可局部横滚；表格有表头，图形有替代说明；键盘可以展开答案、翻章节和返回练习。正文不能借助超宽图、PDF 裁图或缩小字号来塞进页面。

第二阶段已实现一个课程、一套章节 ID、一份阅读进度，内容语言与界面语言独立切换。通用课程格式增加可选 `localizations`，兼容已有单语言课程。各专题中英文文档仍作为两份同结构的编写源文件；统一导入将已编写专题组合到同一门双语课程，不再按语言或专题分别创建课程。新增可选 `sections` 与课时 `sectionKey`，无专题的既有课程继续平铺；专题名称、分组标题也有中英译文。

## 进度、评估和奖励

| 状态 | 依据 | 不代表 |
| --- | --- | --- |
| 已读 | 学生主动标记该章节已读 | 已掌握或真题答对 |
| 自测已核对 | 学生对照原创练习解析 | 自动评分或考试成绩 |
| 笔试已交卷 | ACSL 已保存整卷成绩 | 本专题全部掌握 |
| 编程已通过 | 本人正式提交得到 AC | 样例运行通过即可 |

“自测已核对”描述学生的自查行为，首批不新增持久化状态。首批沿用课程已读记录，不为打开页面、点击“已读”或展开自测答案发积分。正式 ACSL 积分仍按既有规则结算。后续若加入专题测验，应使用独立原创题及服务端判分，并单独确定重试、提示使用和奖励规则；不能复用正式试卷成绩或重新奖励旧答卷。

## 实现顺序

- **已完成：内容样板**。中英文同构的四节数制课、来源说明、原创算式验证和既有导入格式检查。样板中普通题 UUID 列表为空，不把 ACSL ID 塞入普通题接口。
- **已完成：课程与真题关联**。增加轻量 ACSL 关联适配器。引用按课程学校解析，固定试卷版本和题号；读取时同时检查课程与试卷权限；历史成绩仍取已保存结果。状态来自服务端已有成绩，只读关联不能发分或解锁答案。
- **已完成：学习闭环**。从复盘到相关教程、回到原题、教师关联管理，以及单课程的中英切换。课程下架或试卷不可用时显示明确状态，禁止仅凭 URL 绕过权限。本地样板保持未发布，学生流程使用隔离账号和课程验收。
- **第三阶段：C1 内容扩写**。递归函数与程序追踪各三节，配套自测、执行状态校验和 20 道真题关联；验证范围单独记录，不沿用数制的检查结果。
- **第四阶段：C2 内容扩写**。表达式、位串运算和 LISP 各三节，共 32 道真题关联；使用独立运算校验、隔离学生流程和本地教师预览验收。
- **已完成：统一课程目录**。六门未发布专题草稿已在 3004 合并为同一课程，保留主课程与全部课时 ID、双语进度和固定版本关联；其余来源草稿归档为旧链接入口。教师、学校、平台编辑与通用阅读器支持专题，统一课程仍为草稿；实际验收范围见 [统一课程说明](acsl-unified-course.md)。
- **第五阶段：C3 内容扩写**。布尔代数三节、数据结构四节、有限状态机与正则表达式四节，配套原生树图／状态图、原创自测和 32 道真题关联。追加到既有统一课程，保留前十九课的身份及学习记录；见 [C3 扩写记录](acsl-tutorial-c3-expansion.md)。
- **后续：逐专题扩写**。按 C4 图论、数字电路和汇编语言继续扩展。每个专题内容和交互都通过验收后加入同一门课程，再按课程原有发布规则安排开放，不向学生展示未完成的空教程列表。

不自动把本地 `curriculum.json` 的编辑索引当作运行时授权。原校使用现有 `learning_paths/learning_chapters`，新校使用 `school_courses`，共同复用 `LearningCourseReader`。结构化关联使用独立领域约束和增量迁移，编写源文件不硬编码数据库 UUID。

## 样板验收标准

- 四节中英目标、例题、自测和参考解析对应，原生 KaTeX 编译通过。
- 位值、转换、进位、结果可独立计算验证；原生竖式各列和进位对齐。
- 课件通过前端 Markdown 导入解析与领域格式校验，导出再读内容一致。
- 教师可预览／编辑草稿；学生不能读取未发布草稿；隔离库发布后能够标记已读并在刷新后恢复。
- 自测答案初始折叠，桌面／手机正文可读，长公式不撑宽整页。
- 样板不写真实学生成绩、真题答卷或奖学金；没有创建新积分奖励。
- 每批验收记录明确说明实际执行范围，不将自动格式检查说成所有教学内容已被学生验证。
