# ACSL 练习内容

本目录是服务端内容包，包含 2020–2021 至 2025–2026 六个学年的 96 套完整轮次：Elementary、Junior、Intermediate、Senior 各 24 套。共 512 道笔试题、72 道编程题；Elementary 原卷只有笔试。

- [按学年、组别和轮次查看全部试卷](CATALOG.md)
- [2002–2015 专题练习来源索引](historical/README.md)：19 组题目／解析资料，单独整理，尚未作为完整轮次导入。

## 内容组织

```text
sample.json                                   # 原有 Junior 2025–2026 第三轮样板
editions/<学年>/<division>/contest-<轮次>/
  paper.json                                  # 其余 95 套内容及来源元数据
historical/
  README.md                                   # 旧专题来源清单
  index.json                                  # 路径、SHA-256 和页数
```

`sample.json` 保留原内容与版本，不在 `editions` 中复制，以免改变已保存的答题和判题记录。每份 `paper.json` 的 `slug` 标识学年、组别和轮次。目录名“资格轮”对应官方 Contest 1，保留在 `roundLabel`，排序仍使用 `round: 1`。

## 笔试原题与解析

现代原卷的 512 道笔试题均为单选，每题保留原来的选项字母。Elementary 2020–2021 第三轮第 1 题只有 A–D 四个选项；其余题为 A–E。系统的多选能力使用独立测试资料验证，不会给原题添加选项或改变题型。

所有题目使用系统原生内容：题干与真实选项分别保存为中英文 Markdown，数学公式使用 KaTeX，程序使用保留缩进的代码块，表格保留行列关系。树、图、逻辑电路及编程例图使用受限 SVG 图元重新渲染。当前内容包不引用 PDF 切图，不使用“Option A”占位选项，也不在题干中附带答案列。

各包 `sources` 保存原文件相对路径、SHA-256 和页数；各题 `source` 保留题面、解析页码及答案来源。图元仅允许有限坐标、预设颜色和安全路径，不能嵌入图片、脚本、外部链接或任意 HTML。解析文本和解析图只在整份笔试交卷后，按学生主动请求返回。首次批量导入使用裁图的呈现方案已由本次原生内容修正替代。
507 道笔试题有提供的官方答案；Senior 2020–2021 第四轮缺少官方笔试答案文件。该轮 5 道题采用依据原题独立推导并交叉核验的中英文解析，题内明确标注为自行推导，未冒充官方答案。

已核对选项引用、每套题目顺序、中英题目对应、答案列和跨页边界。少量原稿问题保留在各包 `contentNotes`：例如 Junior 2020–2021 第二轮答案册将第 2 题标题误写为第 1 题，而右侧答案列仍标为第 2 题。系统关联按题目顺序及答案列处理；转录时分开题干、选项及解析，保留数学含义。

## 编程题

编程题复用现有隔离判题模块。题面、数学公式、表格及独立例图均为原生内容；公开样例与正式测试分别保存，正式测试及参考程序不进入学生题面。

71 份新编程题按官方样例／测试及来源元数据导入；原有样板继续保留参考程序。未提供参考程序的试题不伪造参考实现。具体标准输入格式以系统中的输入约定为准，原卷中的“多组数据”列表按独立测试用例组织。任何参考程序或学生程序都只能交给隔离判题器执行。

2020–2021 第四轮的三份编程 PDF 为扫描版；公开样例及正式测试输入输出已对照原图逐项转录，未直接采用 OCR 的数字结果。三份资料各有五组公开样例及五组正式测试。

原生转录另核对并处理了以下来源问题，未改变样例、正式测试或评分规则：

- Junior 2024–2025 第二轮的中文译本缺少末页，题包依据同份英文原卷补译最后的演示步骤及输入输出，并复用同题已有例图。
- Junior 2025–2026 第一轮的横向／纵向移动描述颠倒，按坐标、数值和规则统一；Junior 2024–2025 第三轮中文例示第六行的起点按英文及构造规则从 25 更正为 26。
- Intermediate 2023–2024 第四轮原 PDF 重复使用同一张中间／末状态插图。题包保留原图引用，程序行为仍按文字规则和正式测试判定。

## 原有样板

`sample.json` 是服务端内容包，含六道笔试单选题、答案与解析，以及一道 Kings in the Corners 编程题的六组公开样例、六组正式测试和参考程序。学生接口应按访问权限投影题面，提交后再按请求返回解析。

### 样板来源与核对

内容来自 `resource/acsl-problems/Junior/2025-2026/第三轮/` 中用户提供的三份 PDF。包内 `sources` 保存各文件的相对路径、SHA-256 和页数，各题 `source` 保存一基页码。

- 笔试 PDF 第 1、2 页为空白。第 3–5 页为英文题面，第 6–8 页为中文题面。
- 笔试答案第 1 页覆盖第 1–4 题，第 2 页覆盖第 5、6 题。正确选项依次为 D、C、D、E、A、D。
- 已按渲染后的原页核对布尔表达式取反线、全部选项、伪代码、数组及测试数据。
- 第 5 题题面使用 `if count != 3`，答案册使用 `if count < 3`。包内保留题面写法，两种写法在该题给定数据上均输出 32。
- 中文解析依据英文答案翻译并补充步骤。二叉树图转为结点关系表，扑克牌布局转为编号图及出牌过程表。编程题补充了每次出牌后从手牌左侧重新检查的明确说明，与原卷示例一致。

### 样板练习约定

六道原题均为单选。多选组件与判分能力使用独立测试资料验证。

编程题采用两行标准输入。第一行为手牌，第二行为按顺时针排列的四个初始牌堆。每次运行只处理一组数据。

Python 参考程序按题意编写。程序只可通过现有隔离判题器执行。公开样例和正式测试的预期输出均从原卷转录。时间限制 1000 ms、内存限制 128 MB 是本地练习设置。

正式用例权重总计 100，四位小数分配为前四组各 16.6667、后两组各 16.6666。全部六组通过后才判为 AC。

本包已通过结构、选项引用、中英文 KaTeX 公式和既有 `normalizeSchoolProblem` 判题任务格式检查。样板此前的本地隔离判题中，参考程序通过全部六组公开样例与六组正式测试，固定输出八个空牌堆的错误程序得到 WA、0/6。运行证据保存在本地忽略目录 `.campus-local/acsl-qa/reference-check.json`。

## 已导入试卷的展示修正

`acsl-presentation.mjs` 提供独立的事务更新命令。清单必须带待更新包和审核时的旧内容哈希；只允许题干、选项文字、公式、图形与解析等展示字段变更。正确选项、题号及选项 ID、题型、版本、测试、权重、参考程序和判题限制必须保持一致。更新以负责人账号写入审计记录，保留更新前后定义；不重建题目版本，不清空草稿、成绩、提交、积分或奖学金。

```sh
node packages/domain/src/acsl-presentation.mjs --school-id SCHOOL_UUID --actor-account-id ACCOUNT_UUID --manifest MANIFEST_PATH --dry-run
node packages/domain/src/acsl-presentation.mjs --school-id SCHOOL_UUID --actor-account-id ACCOUNT_UUID --manifest MANIFEST_PATH
```

内容回归检查：`node --test packages/domain/test/acsl-content.test.mjs`。
