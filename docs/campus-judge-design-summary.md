<a id="overview"></a>

## 一、产品定位

- 校内本地部署的教学型 Online Judge，面向高中 Python 初学者，兼顾 ACSL Intermediate 与 CIE 9618 Paper 4 训练。
- 核心教学闭环：**学习 → 练习 → 自测 → 正式提交 → 结果 → 订正 → 教师跟进**。
- 三类角色：学生、教师、管理员。

<a id="visual-design"></a>

## 二、视觉与交互规范

- 浅灰页面底、白色内容区、克制的蓝色主操作；不使用渐变、玻璃拟态、营销横幅、大型统计卡。
- 正文 Arial / 系统无衬线（中文系统字体回退）；代码使用等宽深石板灰。
- 编程工作区桌面端约 44%（题面）/ 56%（编辑器）分栏，各自独立滚动；全局侧栏默认收起。
- 学生题面以英文为主，附少量中文易错提示。
- 所有页面标注 `Prototype · Sample data`；未制作模块明确标"后续版本"，不留死链接。
- 教师与管理员左侧一级导航统一为英文；页面内部中文待完整中英文化时再处理。

## 三、各轮次设计内容

<a id="round-1"></a>

### 第 1 轮：学生端基础原型

- 默认首页为学生工作台（示例身份 Emma Chen）。
- 题库列表：搜索、筛选、收藏外观、空结果与无权限固定视图。
- 两个完整编程工作区：
  - **P101 A+B（Standard I/O）**：保留原完整题目与工作区；后续本地 A+B 导入示例另要求读至 EOF，`0 0` 不是终止条件，不覆盖 P101。
  - **P104 Row Sums（Python Function）**：接口 `def row_sums(grid):`，返回二维列表每行和、不修改输入；提示 "Return the result. Do not print it."；示例 `[[1,2,3],[4,5,6]] → [6,15]`。
- Run Samples / Run Custom Input / Submit 三按钮分离；自定义运行无期望输出时显示"执行完成但尚未判定"，**不得显示 AC**；样例通过不代表正式评测通过。
- 13 种固定评测状态由工具栏手动切换、不自动推进：尚未运行、样例通过、公开输出差异、Waiting、Judging、WA、AC、CE、RE、TLE、MLE、OLE、System Error。**System Error 不记为 0 分**。
- 提交记录：SUB101042（WA 75/100，6/8）与 SUB1048（订正 AC 100/100，8/8）构成订正链路；隐藏测试只显示允许公开的结果。
- 离开有临时编辑内容时弹确认，不承诺保存。

<a id="round-2"></a>

### 第 2 轮：教师端与作业

- 教师工作台、班级与学生（Classes & Students）、作业管理（T01–T06）、学生作业详情（S06）。
- A03 作业进度矩阵（475/600 固定示例）。
- 班级页可切换三个班级（高一1班、高一2班、CIE 9618 P4），各班显示各自名单与进度；支持新建班级（名称必填查重、可勾选已有学生，学生保留原班级）。

<a id="round-2-import-v11"></a>

### 第 2 轮后 v1.1：本地题包导入演示

- 当轮默认演示 `1.zip`：1 道题、1 组公开样例、1 对正式测试文件；103 组输入只算 1 个正式测试点。
- 补齐 `problem.md`、测试文件自动配对、可选配置省略、无 pid、来源 owner、历史提交统计和标签清理的展示规则。
- 结果显示“本地数据已识别·待本机校验”，串联测试详情、配置确认、校验准备、校验通过示例与独立发布预览。
- 保留 `ybtbas.zip` 远程分支；人工缺文件案例单独标为错误示例；学生预览保留中文原题。
- 此轮本地 A+B 题读至 EOF，`0 0` 不是终止条件；公开样例与正式测试分开，原 P101/P104/A03 及历史提交不覆盖。
- **后续被替代的部分**：下一轮通用导入移除特定题包默认卡片和专属分析页；以上保留为演进记录，不是当前入口要求。

<a id="round-2-repair"></a>

### 第 2.1 轮：题库、导入与统一编辑器（UI 修复）

- "Problem Management" 改为 **Problem Banks**：题库列表、新建空题库、题库详情、空态。
- 通用导入四阶段流程：**选择文件与去向 → 预览题目 → 确认导入 → 结果页**；去向支持"创建新题库"或"加入已有题库"；文件树/来源/格式说明仅作折叠辅助内容。
- **统一编辑器**：手工题、已有题、导入题共用同一套编辑器，点哪道开哪道。
- 测试维护：公开样例与正式测试分开；支持添加、编辑、复制、删除；标准 I/O 题编辑输入/期望输出，函数题编辑参数/期望返回值；单文件就地替换、批量补测试后返回该题测试页。
- 移除了特定题包（1.zip、ybtbas.zip）的默认卡片与专属分析页。

<a id="round-2-groups"></a>

### 第 2.1 补丁：题目分组（UI-GROUP-FIX）

- 分组 = 题库内部的章节/分组；一道题可属于零个、一个或多个分组，多组只引用不复制。
- 三种操作语义：**添加到分组**（保留原有归属）、**移动到分组**（明确来源与去向，确认前展示"从哪里移出、向哪里加入、哪些保留"）、**从本分组移除**（只删本组归类）。
- **未分组**是无任何真实分组归属的视图，不是可与分组同时勾选的实体。
- 分组调整不改题目内容、判题规则、发布状态、权限，不影响已有作业/提交/成绩。
- 入口：题目行分组标签（多组显示前两项 +N）、行内"管理分组"、批量工具条、未分组视图"分配分组"、编辑器入口、已有题目抽屉选目标分组、导入结果"整理分组"、跨题库混合选择时提示"请选择一个题库后批量整理分组"。
- 统一"管理分组"弹窗：单题与批量复用，可搜索多选、可新建分组，确认摘要区分新增与已存在归类；确认按钮用具体动词。
- 分组管理：新建、改名（会话内同步）、解散（不删题目）。

### 第 3 轮：学习、订正、计时训练与教学报告（UI-R3）

- **S08 订正本（Review Notebook）**：区分原活动 SUB101042 与独立订正 SUB1048；短笔记、代码对比、教师反馈、再次练习；提交详情可加入订正本；教师 A03 矩阵抽屉展示原提交、订正、学生笔记与可临时编辑的教师反馈（不改 475/600）。
- **S07 计时训练（Timed Practice）**：学生列表、T01 规则、开始确认、固定倒计时工作区、结束确认、未发布/已发布结果、赛后订正预览；工作区按训练来源显示题目导航、固定剩余时间、Draft only/Submitted/Judging 状态。

- 作业编辑器：Problems 页签支持题库/分组/搜索去重选题、导入、逐题分值、调序、打开编辑器、移除；Applicable list 支持搜索、全选/清空、勾选适用/豁免与实时计数。

<a id="identity-model"></a>

## 四、身份与账号模型（方案一，已确认）

**核心决策：学生/教师身份档案与登录账号分离，身份先行、账号后绑。**

- 身份档案（学号/工号、姓名、班级）由管理员独立维护，**导入名单不受账号限制**；成绩、提交、订正记录始终挂在身份档案上，换账号/重置账号不丢数据。
- 学生首次使用通过**注册页一次性认领身份**：学号 + 姓名 + 激活码 → 自行设置用户名与密码。管理员**不代建账号**。
- 选择"注册即认领"而非"先建账号后关联"的理由：避免孤儿账号窗口期、避免学生停在不关联那一步、管理端少一类"已注册未关联"状态；激活码用于校验认领资格；姓名和编号用于核对档案。注册认领只完成身份关联，并不等于授予所有内容权限。

<a id="account-page-responsibilities"></a>

### 各页面分工

| 页面 | 职责 |
|---|---|
| 注册页 /register | 三步：验证身份（学生/教师切换）→ 设置账号 → 完成；固定示例：激活码已使用 / 已失效 / 身份不匹配，各含重新输入指引 |
| 登录页 /login | 日常登录（无需重复验证身份、无强制改密）；忘记密码 = 联系管理员重置；固定错误示例：空字段、凭据不匹配、账号不可用、服务暂不可用 |
| Admin → People & Identities | 身份档案列表（学生/教师 tab、搜索、激活状态筛选）；新建身份（无需账号，生成激活码）；详情：激活码+复制按钮、重新生成、关联/解除账号、编辑资料（姓名/编号/班级/备注） |
| Admin → Accounts & Roles | 账号只用于登录；无主批量导入/新建账号按钮；"生成激活码"支持筛选、全选、批量生成、逐个复制、复制全部；编辑仅限角色与账号状态 |
| 学生/教师个人资料 | 入口统一在左侧栏底部；身份信息只读（提示联系管理员更正）；账号信息可自改邮箱、密码（≥8 位、两次一致） |

<a id="technical-boundaries"></a>

## 五、技术边界（全程有效）

- 仅组件内临时状态与固定示例常量；**禁止**后端、API、数据库、真实鉴权、代码执行、判题、计分、排名、持久化、定时器、轮询、WebSocket、真实文件解析（Excel 预览解析除外）、AI。
- 不使用 localStorage / IndexedDB / Cookie 伪造状态。
- 技术栈：TanStack Start v1 + React 19 + Tailwind v4；路由文件每页独立 head 元数据。
- 注册/登录的示例场景与校验保留在共享页面，原生 label 表单 + 内存状态，所有设备尺寸同一流程。


<a id="boundary-allowed"></a>

### 允许范围

高保真页面、基础导航、固定示例、临时表单编辑、预设确认/结果视图。运行、提交、发布、运维操作只展示预设状态，不执行真实任务。

<a id="boundary-prohibited"></a>

### 禁止范围

不接后端/API/数据库/真实鉴权，不执行代码或判题，不产生真实分数/排名，不使用定时器、轮询、WebSocket、AI 或持久化；不以 localStorage、IndexedDB 或 Cookie 伪造真实业务状态。

<a id="boundary-files"></a>

### 文件导入的后续例外

初始范围禁止真实文件解析；后续为修复真实名单上传，允许浏览器端 Excel 预览解析。该例外不扩展为真实题包校验、服务端导入、文件存储或真实建档入班。题包识别与本机校验/发布仍按预设示例展示。

<a id="boundary-state"></a>

### 状态与安全语义

注册、登录、激活码生成等只在原型内展示，不创建真实账号、不核实真实角色、不承诺保存或真实失效。系统故障不当作学生错误或 0 分；公开样例通过不等同正式 AC；隐藏测试不暴露不允许公开的内容。身份认领与内容授权是不同概念。

<a id="boundary-stack"></a>

### 技术栈与共享流程

沿用 TanStack Start v1、React 19、Tailwind v4；各内容页面独立元数据。师生使用共享注册、登录和资料界面；注册/登录校验使用有标签的原生表单与内存状态，不为不同设备建立不同认领流程。

## 八、按轮次排列的决策时间线

记录顺序来自历次需求与修复记录，不虚构精确实施日期。每条分开记录背景、结论与影响；“历史方案”不代表现行要求。

<a id="decisions-r1"></a>

### 第 1 轮：学生体验与评测语义

<a id="decision-d01"></a>

#### D01 · 原型范围

- **背景**：需要先验证教学操作路径，而不是接入真实判题服务。
- **结论**：默认首页为学生工作台；只做高保真页面、固定示例与基础导航。
- **影响**：确定所有轮次的原型边界；后续功能不自动获得真实执行能力。

<a id="decision-d02"></a>

#### D02 · 工作区与操作分离

- **背景**：高中初学者容易把样例通过当作正式评测通过；按钮曾落到视口外。
- **结论**：桌面 44%/56% 独立滚动；Run Samples、Run Custom Input、Submit 分开且底部可见。
- **影响**：明确自测与正式提交区别；无期望输出不显示 AC。

<a id="decision-d03"></a>

#### D03 · 结果与订正

- **背景**：需要展示错误、系统故障和进步，又不能泄露隐藏测试。
- **结论**：13 种状态手动切换；系统错误不记 0 分；原提交与订正分开。
- **影响**：保留 SUB101042 与 SUB1048 链路，避免订正覆盖历史结果。

[返回目录](#contents)

<a id="decisions-r2"></a>

### 第 2 轮、v1.1 与操作路径/分组补丁

<a id="decision-d04"></a>

#### D04 · 增量建设

- **背景**：初版已可用，新增教师功能不能打断已有学生工作区。
- **结论**：沿用现有视觉、导航和共享界面；连接教师端、学生作业与 A03。
- **影响**：保留班级、作业、题目来源和返回上下文。

<a id="decision-d05"></a>

#### D05 · v1.1 本地题包解释

- **背景**：真实题包含 103 组输入，容易误算为 103 个正式测试点。
- **结论**：按一对输入/输出文件计为一个正式测试点；公开样例另计；本地 A+B 读至 EOF。
- **影响**：展示待本机校验与发布预览；不覆盖原题及提交；特定默认题包入口后来撤下。

<a id="decision-d06"></a>

#### D06 · 通用导入替代专属入口

- **背景**：默认特定题包卡片与分析页偏离普通教师的日常导入路径。
- **结论**：选择文件与去向 → 预览 → 确认 → 结果；可新建题库或加入已有题库。
- **影响**：专属题包入口退役；文件树与格式说明降为折叠辅助信息。

<a id="decision-d07"></a>

#### D07 · 统一编辑与测试维护

- **背景**：新建题曾打开 P104；导入题与手工题操作割裂。
- **结论**：所有题目共用编辑器并打开所选题；测试可添加/编辑/复制/删除/替换。
- **影响**：题目上下文保持；批量补测试返回原题测试页。

<a id="decision-d08"></a>

#### D08 · 多组归类

- **背景**：题目需要多章节归类，移动与删除容易造成误解。
- **结论**：添加保留原组；移动明确来源；移除只删本组引用；未分组不是实体组。
- **影响**：不复制题目、不建内容版本、不改变作业顺序/分值/提交/成绩。

[返回目录](#contents)

<a id="decisions-r3"></a>

### 第 3 轮：教学闭环与作业修复

<a id="decision-d09"></a>

#### D09 · 学习与订正分工

- **背景**：练习之外需要结构化教学和独立订正记录。
- **结论**：S05 学习路径、S08 订正本；2D Lists 连到 P104；原活动与订正记录分开。
- **影响**：教师可以跟进笔记和反馈，不改原活动成绩示例。

<a id="decision-d10"></a>

#### D10 · 计时训练与报告

- **背景**：训练与教学分析需要完整操作路径，但禁止真实计时/计分。
- **结论**：S07 采用固定时间与状态；教师操作使用独立确认；报告提供带分母指标和行动名单。
- **影响**：避免伪实时效果；可查学生/题目并保留筛选。

<a id="decision-d11"></a>

#### D11 · 作业选题与选人

- **背景**：教师布置作业时不能选题、编辑、导入或选择目标学生。
- **结论**：题库/分组/搜索选题去重，可改分值/顺序；适用与豁免名单可搜索和勾选。
- **影响**：布置作业成为完整可点击流程，而非只填基本信息。

<a id="decisions-r4"></a>

### 第 4 轮及后续账号/身份修复

<a id="decision-d12"></a>

#### D12 · 本地账号与运维

- **背景**：需要补齐登录、成员管理和本地部署管理界面。
- **结论**：本地账号登录、固定错误状态；判题服务快照、设置、备份恢复、审计。
- **影响**：演示身份与真实角色获取分开；服务故障不变成学生 WA/0 分。

<a id="decision-d13"></a>

#### D13 · 导入入口与班级目标

- **背景**：直接进入 Import Center 看不到 Member import；目标班级只有一个选项。
- **结论**：两类导入可切换；支持已有班级、不指定、按文件班级列，并预览自动建班。
- **影响**：班级入口保留返回路径；名单导入不被单一班级限制。

<a id="decision-d14"></a>

#### D14 · Excel 预览例外

- **背景**：上传真实名单提示无法解析，固定示例无法反映文件内容。
- **结论**：加入浏览器端 Excel 预览解析，不接服务、不持久化。
- **影响**：这是对早期禁止真实文件解析的有限例外；不是完整后端导入。

<a id="decision-d15"></a>

#### D15 · 方案一：身份与账号分离

- **背景**：名单中学生没有账号，旧成员导入因此阻止入班。
- **结论**：用户确认身份先行：学生/教师档案独立于账号，名单导入不要求已有账号。
- **影响**：待激活身份可入班、参与教学名单；记录挂在身份上；旧“只能加入已有账号”规则退役。

<a id="decision-d16"></a>

#### D16 · 独立身份维护

- **背景**：管理员只能新建账号、填写用户名，无法单独建人或纠正资料。
- **结论**：新增 People & Identities：无账号建身份，可编辑姓名/编号/班级/备注。
- **影响**：身份与登录凭证职责分离；更正资料不转移或删除历史记录。

<a id="decision-d17"></a>

#### D17 · 自主注册与激活码

- **背景**：管理员代建账号与用户通过激活码自主注册相矛盾。
- **结论**：撤下账号页代建/批量导入主按钮；账号编辑只改角色/状态；提供激活码批量生成与复制。
- **影响**：用户名和密码由用户创建；身份修改回到档案页；重新生成码替代旧码。

<a id="decision-d18"></a>

#### D18 · 个人资料入口统一

- **背景**：师生入口位置不同，且缺少本人维护账号信息的途径。
- **结论**：师生均从左侧底栏进入共享资料页；身份只读，邮箱/密码由本人修改。
- **影响**：管理员负责更正身份，账号持有者负责日常账号维护。

<a id="decision-d19"></a>

#### D19 · 注册即认领

- **背景**：需要避免冒领已有身份，同时讨论了先建账号后关联的替代方案。
- **结论**：当前保留三步：核对身份与激活码 → 自设账号与密码 → 完成。
- **影响**：减少未关联账号的中间状态；不宣称这是唯一通用模式，也不等同于拥有全部权限。

<a id="decision-d20"></a>

#### D20 · 手机/平板与异常指引

- **背景**：注册和登录在小屏上的输入、返回与错误恢复需要一致。
- **结论**：共享页面使用有标签的表单、内存状态；补齐已使用/失效/不匹配及登录错误、忘记密码。
- **影响**：四种宽度记录为 Chromium 历史验证；其他浏览器仍待验。

<a id="decision-d21"></a>

#### D21 · 取消首次登录强制改密

- **背景**：用户已自行设置密码，首次改密属于早期管理员发初始密码模式遗留。
- **结论**：删除首次登录强制改密；日常登录不重复认领身份；统一两页文案。
- **影响**：保留本人主动改密与忘记密码联系管理员的指引；不混为同一流程。

<a id="decision-d22"></a>

#### D22 · 设计文档归档（2026-10-11）

- **背景**：多轮迭代信息分散，旧方案与当前规则容易混淆。
- **结论**：将总结放入 docs，增加目录、页面/决策/技术边界锚点及背景—结论—影响时间线。
- **影响**：文档可快速定位；历史变更标出替代关系，验收状态不冒充本次验证。

<a id="decision-d23"></a>

#### D23 · 从原型进入生产设计（2026-10-11，第 5 阶段）

- **背景**：最终设计仍禁止真实鉴权、持久化与判题，与学生实际使用目标不符；用户明确选择“开发能实际供校内学生使用的完整 OJ（需先补齐生产设计）”。
- **结论**：保留原型作为界面与预览依据，新增生产设计基线。原型限制继续适用于预览模式；真实业务允许并需要服务端、数据库、会话、隔离判题与任务查询。注册/登录预览仍使用共享页面内存状态，生产流程复用界面并与预览模式隔离。
- **影响**：补齐身份名单导入、版本快照、成绩与重判、计时边界、资源权限、安全执行和验收要求；生产取分、沙箱及部署默认方案为待验证实施基线，不声称已实现或上线。原“管理员账号导入”被身份名单导入替代；SUB101042 为旧示例编号，后续统一 SUB1042。

<a id="decision-d24"></a>

#### D24 · 首期生产实现与本地验收（2026-10-12，第 5 阶段后续）

- **背景**：用户确认 Ubuntu 26.04、4 核 / 8 线程、16GB、Docker，总学生约 200，单堂课 30–50 人。原型缺少服务器授权、可靠判题、历史成绩与教学活动边界。
- **结论**：新增独立 API/PostgreSQL、受限数据库角色、go-judge/Python 3.12 沙箱与租约任务队列；按原型布局完成账号、班级、题库、作业、学习、计时训练、订正、报告和管理页面。初始评测并发 2，单任务累计 CPU 30 秒 / 墙钟 60 秒。作业取截止前最高有效分；训练取截止前最后提交；平台错误无分数；重判先产生候选，再明确确认，已发布训练成绩保存不可变修订。
- **影响**：原型共享登录/注册的内存预览保持；生产同页接入真实会话，不显示场景选择器。68 项实际数据库/执行器测试全部通过且没有跳过，受限角色全链路与 50 学生真实会话负载完成，本地独立库备份恢复通过。开发机结果不代表学校硬件验收；校园 HTTPS、题目授权与内容、留存策略以及学校隔离/容量/恢复验收仍是正式开放条件。ZIP、可执行 checker、跨库复制、单题豁免、ACSL 短题与邮件服务不属于本次完成范围。

<a id="decision-d25"></a>

#### D25 · 本机生产版体验环境（2026-10-12，第 5 阶段后续）

- **背景**：用户要求在本机启动完整生产版，并提供管理员、教师、学生测试账号体验教学流程。
- **结论**：使用独立本地 Compose 项目、演示数据库、构建后的生产界面和真实 Python 判题；本机 HTTP 入口为 `http://127.0.0.1:3000/login`。自动生成随机测试密码与服务密钥，私有文件权限 600，不进入版本控制。
- **影响**：新增 `npm run start:local` 启动入口，创建班级、两题作业、学习路径、尚未开始的计时训练，以及真实 WA→AC 订正报告。重启保留账号、改密与体验数据；学校部署继续使用 HTTPS 与严格生产配置。三角色密码仅供此次本机体验，不是学校正式账号。

<a id="decision-d26"></a>

#### D26 · 原型与生产分离并更换框架（2026-10-12，第 6 阶段）

- **背景**：用户指出生产实现直接混入原型代码库不符合要求，并已将纯原型单独保存到 `myoj/`。
- **结论**：`myoj/` 保持独立 Git 仓库及原文件不变；真实系统完整置于 `production/`。前端采用 Next.js App Router、React 和 TypeScript，API 采用 NestJS 和 TypeScript，数据库及隔离判题仍使用 PostgreSQL 与 go-judge；所有生产依赖、构建、配置、测试和部署脚本在该目录独立维护。
