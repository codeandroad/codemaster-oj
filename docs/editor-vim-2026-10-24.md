# 代码编辑器 Vim 模式（2026-10-24）

## 入口与范围

普通题与 Paper 4 答题页：代码区齿轮 → 代码编辑器 → 键位绑定 → Vim。默认仍为标准键位，可随时切回标准或 Emacs；沿用现有账号维度的浏览器设置，不上传服务器。底部状态栏显示当前模式和待执行命令/搜索文字。

沿用现有 textarea、高亮、代码主题、草稿、运行和提交入口，没有替换编辑器，没有增加依赖。此轮仅更新本地 3000 的 web；不推送、不更新线上。不涉及数据库迁移或业务数据修改。

## 已支持键位

| 操作 | 键位 |
| --- | --- |
| 插入及返回普通模式 | `i a I A o O`；`Esc` / `Ctrl+[` / `Ctrl+C` |
| 逻辑行/字符/词移动 | `h j k l`、方向键、`w b e`、`0 ^ $`、`gg G`；次数前缀上限 999 |
| 删除/修改/复制 | `d c y` + 移动、`dd cc yy`、`diw ciw yiw`、`daw caw yaw`、`x X D C s S Y` |
| 内部寄存器粘贴 | `p P`（与系统剪贴板分开；系统粘贴请进入插入模式） |
| 选择 | `v` 字符选择、`V` 行选择；移动后 `d c y`，`Esc` 取消 |
| 其他编辑 | `r` 替换、`J` 合并下一行、`f F` 行内查找 |
| 撤销/重做 | `u` / `Ctrl+R`；一次插入或修改及其后续输入作为一组 |
| 字面查找 | `/` 输入文本，`Enter` 查找；`n N` 继续/反向，支持首尾循环 |
| 半页移动 | `Ctrl+D` / `Ctrl+U`（按 10 个逻辑行移动） |

这是一套常用 Vim 键位，非完整 Vim：不支持 Ex 命令（包括 `:w`）、点号重复、宏、插件、命名寄存器、可视块或正则搜索。草稿仍按原流程保存，正式提交仍用原按钮/快捷键，不把 Vim 保存解释成提交。

## 实现与保护

- 纯文本键位逻辑位于 `editor-vim.ts`；共用 `CodeEditor` 负责键盘、光标、撤销历史和模式显示。
- 普通/可视模式以只读 textarea 阻止原生输入穿透，但受控 Vim 编辑仍经现有更新函数执行；真正的活动冻结/只读属性始终阻止修改。
- 插入模式沿用原自动缩进、括号补全和原生输入/粘贴。中文文本可输入；普通模式必须先按 `i` 等进入插入模式。
- `Esc` 在 Vim 输入框内用于退出模式，不再冒泡退出面板最大化；运行、提交、保存和原编辑快捷键保留。
- 光标移动、选择、搜索和模式切换不通知草稿所有者，避免触发 Paper 4 自动保存。切换键位不清空代码或撤销历史。
- 控制值提交后在布局阶段同步恢复光标，避免快速连按时旧光标恢复落后于下一条命令。支持 UTF-16 补充字符完整移动/删除，不拆开代理对。

- 代码输入框获得焦点时，标准或 Emacs 键位下按 Esc 即启用 Vim 普通模式；学生普通题与 Paper 4 仍使用原设置存储，刷新和换题继续有效。可在设置中切回标准键位。活动只读、输入法组合状态和弹窗不被快捷键绕过。

## 光标覆盖与辨识度修正

- 用户指出细竖线显示在字符前、看起来像退了一格且不易区分。普通/可视模式改为覆盖当前字符的完整块，使用主题前景作为块底色、主题背景反色绘制字符；插入模式仍为 3px 竖线，直接区分模式。
- 对普通模式测量当前字符的非折叠文本范围，不再采用字符间的插入点。块宽随实际字体和字符变化：14px 默认字体的 ASCII 约 8.44px，中文/补充字符按实际宽度；Tab、空行和文件尾显示一格。块覆盖的字符与 Vim 操作目标一致，按 x 删除的就是所覆盖字符。
