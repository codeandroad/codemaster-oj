# 学习路径的数据与 Markdown 文档规范

## 数据边界

- LearningPath：标题、描述、分类、预计总时长（分钟）、负责人、发布/归档状态。
- Chapter：独立 ID、所属路径、顺序 position、标题、学习目标、Markdown 正文、检查点、Markdown 参考答案。
- ChapterProblem：关联已有题库 problemId / versionId 与排序，不复制题面、测试数据。导入只接受可访问的校内公开题库中已发布题目，并重新绑定当前发布版本。
- LearningProgress：学生身份与章节 ID、已读状态、更新时间。它不写入导出文档，也不等同于解题成绩。
- 资料库 learning_resources 保持独立，用于额外阅读或链接；本次文档只交换路径与章节。

沿用现有数据库表，无须迁移。导入在事务内新建草稿与所有章节；任一章节或题库引用失败时整批回滚。负责人由当前登录账号决定，客户端不能通过文档指定。公开发布仍需教师检查并执行原有发布操作。

## 文件格式 v1

选择 Markdown：可用普通文本编辑器维护、审阅、版本管理。YAML 头部只描述路径；保留章节分隔标题与五个字段标题，正文内部建议使用四级标题。文档以 UTF-8 保存，兼容 BOM 和 Windows 换行。代码围栏内的标题不会被识别为结构。

```markdown
---
format: codemaster-learning-path
version: 1
title: Python 学习路径
description: 学习与练习结合的课程
category: Python
estimatedMinutes: 90
---

# Python 学习路径

## 章节：第一个程序

### 学习目标

独立运行 print。

### 正文

#### 概念

print 将值写入标准输出。

### 检查点

输出整数 5。

### 参考答案

print(5)

### 关联题目

[]
```

正文与参考答案均可包含 fenced code blocks。结构标题 `## 章节：…`、`### 学习目标`、`### 正文`、`### 检查点`、`### 参考答案`、`### 关联题目` 不能用于章节内部普通内容；若需同名正文标题，请使用 `####`。不同章节可以重名，顺序以文件为准。

关联题目字段是 UUID 字符串的 JSON 数组；同站恢复可保留引用。跨站导入可显式勾选忽略原引用，之后在编辑页重新选择题目。示例课程全部使用 []，不伪造题库记录。

## 导入、导出与页面容器

教师：Learning Content → 学习路径 → 导入 Markdown → 选择文件或粘贴 → 检查结构 → 确认导入为新草稿。完整 Python 示例可在同页面下载。新草稿进入路径编辑器后再检查、配置配套题目、保存与发布。

编辑器采用左侧有序目录与右侧章节内容区，目录单独滚动；窄屏上下排列。教师预览与学生阅读共用 Markdown 渲染器，正文、检查点、答案都按内容字段渲染，不根据课程标题注入预设演示内容。

导出入口位于路径编辑页。导出当前本地章节（包含未保存修改），先检查文档可再次导入；空正文或超出限制时不产生文件。导出文件不携带账号、数据库主键、发布状态和学生进度，练习引用仅携带题库 UUID。新导入始终创建另一份草稿，不替换已有路径或进度。

限制：文件与服务端文档最多 512 KB；1–100 章；每章正文最多 256 KB，目标最多 4000 字符，检查点和答案各最多 10000 字符，引用最多 100 项；预计总时长 1–10080 分钟。当前格式仅接受 .md / .markdown，不接受 Word、PDF 或任意无结构文档。

## Python 示例范围

python-learning-path.md 包含 20 章、预计 1800 分钟：运行环境、数值、输入输出、分支、for、while、字符串、列表、二维列表、字典集合、函数、作用域递归、异常、文件 JSON、模块、类、测试、排序二分、复杂度前缀和、综合成绩分析器。

每章有原创讲解、可运行例子与预期输出、常见错误、完成标准、检查点与参考答案。部分检查点答案复用已学函数/类，运行时需一并保留定义；输入练习需按要求提供标准输入。资料练习不自动创建判题题目或成绩。文件读写练习在本机完成，评测环境不假设存在外部文件。

## 学习路径导入路由、练习与双进度

修复 API 控制器遗漏导入路由。新增课程封面/难度与 014 数据库迁移；Python 原始 20 章资料可生成 20 道配套题（100 测试），真实判题全部 AC 后才能发布并关联。学生阅读与正式 AC 任务进度分别统计，教师可查看负责班级学生的双进度；计时练习未公开结果不泄漏为任务完成。安装必须先迁移再重启 API/Web。操作与验证边界见 python-course-testing.md。
