# Paper 4 本地预览说明

本分支提供供学校练习和模拟考试验收的 **Python 3 首版**。普通 OJ 题目、提交、AC 积分和排行榜继续使用原有流程；Paper 4 试卷、草稿、阶段快照、运行任务与教师评分保存在独立的数据表中。运行结果用于核查程序行为，**不会自动折算为 75 分成绩**；教师按阶段评分后发布总分。

## 本地启动与验证

在 Paper 4 worktree 根目录执行 `node scripts/start-paper4-preview.mjs`。脚本只启动 `campus-judge-paper4-preview` Compose 项目，默认使用 `127.0.0.1:3002`、数据库端口 `35433` 和独立的 `campus-judge-paper4-preview_database` 卷，不会重建现有 `campus-judge-local` 实例或连接 rslab。预览私密配置写入被 Git 忽略的 `deploy/.env.paper4.local`，演示账户写入被忽略的 `.campus-local/test-accounts.json`。脚本只在这个独立预览中种入一份**原创改编的三题样卷**，不将 Cambridge 题面、评分细则或考生文件复制到仓库。

启动后打开 `http://127.0.0.1:3002/login`。教师进入“Paper 4 实践评测”，可查看或新建试卷、编写三道大题的阶段与分值、配置输入文件和测试、发布到班级，并在交卷后逐阶段评分及公布成绩。学生进入“Paper 4 练习”，可保存服务端代码草稿、运行当前大题、查看本次公开运行结果和生成的文本文件、保存不可覆盖的阶段检查点，并交卷。两处登录身份来自上述私密演示账户文件；请勿把文件内容提交到 Git。

可以用样卷第二题检查文件型运行：`TheData.txt` 是每次运行的新输入，`Red.txt` 等是本次程序生成或更新的输出。反复运行不应累计上一次运行产生的内容。题目测试可能标记程序行为供复核，但即使公开检查通过，也须由教师给出阶段分数。教师发布成绩前，学生只能看到运行反馈，看不到评分和隐藏测试数据。

## 首版边界

- 仅支持 Python 3、班级范围的练习与模拟考试；试卷总分固定 75 分，教师须为每个阶段评分（包括 0 分）后才能公布成绩。
- 草稿带修订号，跨标签页旧版本写入会被拒绝；阶段快照及发布后的试卷版本不可原地覆盖；提交后代码冻结。截止时，已保存草稿在访问时会由服务端冻结并留给教师批阅。
- 输入与生成文件首版限定为小型 `.txt`、`.csv`、`.dat` 文本文件，按清单及大小限制进入隔离执行器。隐藏用例输入和预期答案只在教师/运行路径使用。
- 尚不支持原卷 PDF 导入、`evidence.doc` 或截图导出、正式 Cambridge 考试的离线监考/交付流程，也不声称自动评分足以取代人工审阅。

上线前仍需按设计草案完成正式题目授权、复杂正确解与错误解的评分比对、多人并发与故障恢复、备份恢复和完整考场流程核验。本地预览仅供功能与交互验证。
