# 浅色认证入口与注册样式统一（2026-10-25）

按用户后续反馈，登录、重置密码和注册各步骤统一改为系统现有浅色风格。此决定替代 D53 的认证入口深色配色，不影响登录后个人工作区主题。

## 变更

- `AuthShell` 移除 `.dark` 和自定义认证配色，直接使用 `globals.css :root` 的浅灰背景、白色面板、蓝色主按钮、边框和文字语义值；去掉蓝紫渐变。沿用原品牌、字体和共享 Button。
- 登录、重置与注册使用同一双栏外框、输入框、主按钮、学校标识和语言页脚。外框与表单顶部固定对齐，避免切换时整体位置跳变；窄屏保持同一品牌头部并改为单栏。
- 学生说明精确改为「课程学习、自由练习」，英文同步简化为 “Courses and coding practice”。
- 注册保留验证身份 → 设置账号 → 完成，详细激活说明收进可展开区域。身份、密码确认字段按可用宽度配对，320px 下恢复单列。登录和注册的连接中/连接失败状态也复用外壳。
- 注册表单改为应用内校验，错误关联字段并聚焦，处理中禁用并阻止重复请求。前端格式提示沿用现有服务端用户名/密码规则；最终身份、激活码与创建权限仍由原 API 决定。邮箱仍可留空/空白并发送 null；密码按原字符比较，不自动 trim。密码和激活码默认遮挡，成功后清空敏感值，不写入存储。
- 不改认证接口、课程、判题或 Luq，不新增依赖或数据库迁移；保留工作区此前未提交的登录页、身份删除等修改。
