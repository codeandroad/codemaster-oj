## 复核与复现

当前逐题对象按规范化 JSON 计算 SHA-256：递归排序对象键、UTF-8、保留 Unicode、紧凑分隔符、无尾随换行。哈希范围由各条 `contentPointer` 标识；原 PDF 使用文件字节哈希。修改题目后需重新生成清单，不能继续沿用旧内容哈希。

汇总脚本使用本轮忽略目录中的分组审计记录，按允许字段输出；不会读取运行时配置或账户数据：

```sh
python3 packages/domain/content/acsl/audit/build-2026-11-10.py --final
node --test packages/domain/test/acsl-content.test.mjs
```

只有各组完成且 577 条记录全部已审时脚本才允许 `--final`。本轮最后重新执行内容测试，2 项通过，覆盖原生公式/图形引用及不变的评分数据。页面、权限、数据库升级和隔离判题的验收另由对应验证记录承载。
