# 页面切换与整屏闪烁修复

对照用户提供的 8.366 秒视频 `redraw.mp4`，在约 2.333、3.000、4.100、4.867、5.567、6.600 秒可以看到整个顶栏、侧栏和内容区一起消失，中央短暂出现“正在连接校内服务…”。原因是生产界面的站内侧栏与多处详情入口仍使用原生 `<a href>`：浏览器每次重新请求完整文档，`ProductionApp` 重新挂载并再次请求 `auth/me`。

本次将管理员、教师、学生的侧栏、工作区切换、表格详情、返回及资料入口统一改为 Next.js 客户端导航。CSV 模板下载仍为文件链接。认证状态和应用工作区移动到根布局，使路由页只校验可访问路径；切换页面时持续保留顶栏、侧栏和会话状态。手机菜单在导航成功后关闭。未保存的站点设置、教师编辑器和学生代码草稿保留浏览器刷新保护，并为站内链接加上离开确认。

最终本地生产构建已部署于 `http://127.0.0.1:3000`。Chromium 实际点击 27 次跨角色侧栏、工作台、详情、返回及浏览器前进／后退链接：**完整文档请求 0、重复 `auth/me` 请求 0、整屏“正在连接校内服务…”帧 0、浏览器异常 0**。另验证五项边界：管理员设置、教师题目、学生代码草稿的取消／确认离开，390px 手机菜单切换，以及直接打开作业详情深链接，全部通过。重建后 92 项管理员／教师／学生桌面与手机页面检查仍全部通过，无页面错误或横向溢出；Web/API 类型检查、Web ESLint 与生产 Web Docker 构建通过。体验账号、原成绩 75、独立订正 100、未开始的作业／训练保持原样。原型 169 个受版本控制文件的内容与 Git 状态一致。

证据文件保存在本地私有目录 `.campus-local/alignment-evidence/`：`no-redraw-verification.json`、`no-redraw-edge-verification.json`、`route-verification.json` 和 `data-preservation.json`。切换到首次打开的业务页时，内容区仍会在真实 API 返回前显示局部加载提示；它不会卸载全站顶栏、侧栏或重新验证登录。直接刷新浏览器会正常进行一次完整文档加载。
