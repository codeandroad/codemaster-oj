# 9618 Paper 4 历年实践卷

根据用户提供的 `paper4.zip` 制作，共 **32 套试卷、96 道大题**，每套保留原卷 **75 分**。英文题面按原卷小题整理，配有可编辑的完整 Python 参考程序、公开与隐藏测试、人工源码复核和证据阶段。

- 2026 秋季不在此次材料范围内。

## 使用

本机教师端 **Paper 4 实践评测** 中已建立对应草稿，可按年份、考季筛选。所有新增试卷均未分配班级、未设置时间、未发布；既有试卷与学生答卷不变。教师核对后选择班级和时间，再发布。

单卷 JSON 是可直接导入的自包含包。目录合集 ZIP 仅用于交付和保存，**请先解压，再选其中一份试卷 JSON 导入**；不能把整个合集当成一张试卷导入。`catalog.json` 是目录索引，也不是导入 manifest。教师端可继续编辑、导出或归档每套试卷。

每套自动测试的参考答案已经过隔离判题器验证。本批共 **712 个自动用例**，所有参考用例通过，所有自动阶段均拒绝空白答案。自动 AC 表示全部自动阶段通过，**75 分成绩仍由教师按原卷源码要求与证据评分**。原卷算法要求、私有属性、递归方式、截图和被后续小题替代的早期主程序，不能仅靠最终输出自动评分；逐项映射见各年份 `coverage.md`。

## 文件与再制作

- 每个年份的 `coverage.md`：原卷小题、分值、判题方式、测试覆盖及原题勘误/约定。
- `sources.json` 或 `source-data.json`：所需文本数据、原件校验值及制作依据；原始 PDF/Word 不打包进系统导入文件。
- `authoring.py`、可选 `common.py` 和 `refs/`：可复现的制作源文件。它们只构建/解析内容；参考和学生程序仅在隔离执行器运行。
- [导入格式](../../docs/paper4-import-format.md)、[制作指南](../../docs/paper4-package-authoring-guide.md)：结构、限制、原卷映射与制作步骤。

合集与每卷包含教师参考答案和隐藏测试，作为教师资料保管，不作为学生附件公开。
