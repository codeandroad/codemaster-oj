# ACSL 教程双语、进度与真题关联

2026-11-12。面向 Intermediate，使用现有课程系统。本文记录数制四节样板的第二阶段实现；其他专题课件仍按 [课程设计](acsl-tutorial-design.md) 分批编写。

## 一门课程，两种内容语言

课程及章节增加可选 `localizations.en`、`localizations.zh`。课程译文包含标题与简介；章节译文包含标题、正文、学习目标、自测及参考解析。原有字段作为兼容的原文，未添加译文的旧课程继续可读。可逐语言维护译文；选择尚未提供的语言时明确提示正在显示原文。

中英文使用同一课程 ID 和同一组章节 ID，不按语言复制阅读记录。内容语言独立于界面语言，同一浏览器按账号记忆；链接中的 `contentLanguage` 可指定当前内容语言。翻章、刷新和往返真题时保留语言选择。

原校课程继续使用 `learning_progress`；新校课程继续使用 `school_course_progress`。新校阅读内容指纹仍按原有标题与正文计算，只增加译文或真题关联不会清空已读。实际修改原文后的处理继续遵守既有课程规则。阅读状态和练习通过状态分开呈现。

教师在现有课程编辑器中维护译文和关联。Markdown 导入／导出保留可选译文与固定版本关联；原 v1 单语文档仍然兼容。教师预览复用章节展示组件，避免学生正文与预览形成两套排版。

## 与正式真题的关系

章节 `acslLinks` 支持具体笔试题、整份笔试及编程题。编辑输入用 `paperSlug`、`kind`、可选 `questionId` 和 `versionId`；服务端按课程所属学校解析，保存固定试卷版本。未修改的关联不会因老师保存章节而自动升级版本。试卷下架、版本变化或学校权限失效时显示不可用状态，不静默跳到另一版本。

关联返回题目标题、题号、可用性和当前学生的学习状态，不携带题干、选项、答案键、解析或正式测试数据。

| 关联类型 | 状态依据 | 计入练习通过的条件 |
| --- | --- | --- |
| 单道笔试题 | 本人保存的草稿／整卷正式成绩 | 整卷已交，且保存成绩中该题正确 |
| 整份笔试 | 本人整卷正式成绩 | 整卷已完成判分 |
| 编程题 | 本人 ACSL 正式提交 | 正式 AC；运行样例不算通过 |

未交卷时只能显示未作答或已保存，不能给出正确性。已交卷后的关联状态读取已保存结果，不重新判旧答卷；如果题目后来修订，明确标记该结果来自历史答卷。教师进度总览按该学生的有效账号读取相同状态，不使用教师本人的答题状态。

积分和奖学金继续由原有 ACSL 判分流程结算。切换语言、阅读教程、展开原创自测、跟随关联或刷新状态均不新增积分，也不解锁正式试卷解析。

## 学习与复盘导航

学生从章节进入具体真题，在真题或编程工作区可返回来源章节。笔试当前题及成绩复盘提供相应章节入口；错题筛选只推荐与当前错题集合有关的章节，编程页只展示编程关联。链接保留原试卷、题号、复盘模式、目录筛选、语言及版本约束。

返回地址只接受当前学校合法的站内学生路由，清理递归上下文和不受支持的参数。URL 只是导航信息，不能替代课程或试卷的服务端授权。课程被撤回后，关联入口及直接读取都继续受权限检查。

## 样板与既有数据

数制题的 [逐章映射](../content/acsl-tutorials/intermediate/number-systems/practice-map.json) 覆盖 12 道题。第一章使用原创基础自测；进制转换章关联 6 题，竖式章关联 1 题，综合运用章关联 5 题。题目由所属学校的已启用目录解析，不把 ACSL 标识塞入普通题 UUID 字段。

默认 [导入工具](../scripts/import-acsl-tutorials.mjs) 从两份编写源文件生成一门双语草稿；目标校缺少引用、同名草稿内容不同或已发布时拒绝静默覆盖。重复导入复用同一草稿。

本地原有两份独立语言样板的升级先核对原文、教师修改、作业关联和全部学习记录。保留英文样板及四章 ID，补齐中文译文和正式题关联；独立中文草稿仅归档保留，不删除内容或重置学生数据。若发现旧草稿已有编辑或进度，应先处理差异，不能盲目合并。

## 学校与公开课程边界

原校和新校课程均支持上述内容结构。ACSL 关联始终按学校权限解析；跨校导入不可用的引用会被拒绝，公开课程的外校读者不会因此获得本校试卷访问权。

公开学习区沿用原有发布规则：译文也只公开标题和正文，校内检查点及参考答案不通过新增 `localizations` 泄漏。公开课程的不可访问真题关联只返回不可用状态，不提供试卷入口、答案或该学生在其他学校的成绩。

数据库迁移 `100_course_localizations_acsl_links.sql` 只增加可选译文、关联字段和索引，不重写历史阅读记录、答卷、成绩或奖励。
