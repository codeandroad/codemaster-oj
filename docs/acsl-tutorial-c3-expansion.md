# ACSL Intermediate C3 教程扩写

2026-11-12。第三轮继续加入同一门 Intermediate 系统课程：布尔代数三课、数据结构四课、有限状态机与正则表达式四课。新增 11 节双语课、44 道原创自测及逐步解析、32 道真题关联；累计九个专题、30 节课和 96 道关联真题。C4 图论、数字电路与汇编语言的九节课仍按计划后续编写，不创建空白章节。

## 教学安排

| 专题 | 递进安排 | 原创自测 | 真题关联 |
| --- | --- | --- | --- |
| 布尔代数 | 逻辑与真值表 → 恒等式、德摩根与横线作用域 → 等价、反例与输入计数 | 12 道 | 11 道，分配为 3／4／4 |
| 数据结构 | 栈队列状态 → BST 插入与重复键 → 深度及内外部路径长度 → 遍历和综合 | 16 道 | 12 道，分配为 6／2／3／1 |
| 有限状态机与正则表达式 | 逐符号接受 → 完整循环与语言 → 正则结构与字符类 → 空串、完整匹配和反例 | 16 道 | 9 道，分配为 2／1／3／3 |

每节先说明约定和最小概念，再用原创数据完整推演，明确常见误读，最后提供自测及按需展开的解析。布尔代数保留逐列真值表和每一步等价理由；数据结构明确根深度为零、重复键向左、真实叶子与空子位置不同；状态机先消费全部输入再决定接受，正则式明确字符类中否定符号的位置及全串匹配。

记号核对依据为 [ACSL Boolean Algebra](https://www.categories.acsl.org/wiki/index.php?title=Boolean_Algebra)、[ACSL Data Structures](https://www.categories.acsl.org/wiki/index.php?title=Data_Structures)、[ACSL FSAs and Regular Expressions](https://www.categories.acsl.org/wiki/index.php?title=FSAs_and_Regular_Expressions)。本地六年 Intermediate C3 的 32 道笔试题用于核定范围；课程不转录正式题的答案或解析，含勘误的 2024–2025 正则题仍由正式试卷版本管理。

阅读、语言切换和自测答案展开不发积分。自测是原创教学内容；关联真题仍在 ACSL 中完成整卷交卷，课程不改变正式题答案、成绩、奖学金或判题规则。

## 原生图形

三幅树图和两幅状态图采用 Markdown 的 `diagram` 围栏，内容为单幅 `AcslDiagram` JSON。复用现有几何元素白名单、坐标与数量限制以及原生 SVG 展示和放大对话框；不接收 SVG 源码、HTML、事件处理器或外部图像地址。无效图形显示明确提示，其他文字可继续阅读。

图形配双语替代描述和等价文字／转移表。正文、学生阅读和教师预览使用所选课文语言；Markdown 导出保留完整可编辑数据。没有新增图形依赖，也没有使用 PDF 裁图。独立视觉复核发现状态机文字压弧线或间距过近，已移动四处标签以留出空白，转移逻辑不变。

## 向现有课程追加

全新环境仍使用 `scripts/import-acsl-course.mjs` 创建一门草稿。已有统一课程使用：

```sh
node scripts/extend-acsl-course.mjs
node scripts/extend-acsl-course.mjs --origin http://localhost:3004 --auth-file PRIVATE_AUTH_JSON
node scripts/extend-acsl-course.mjs --apply --origin http://localhost:3004 --auth-file PRIVATE_AUTH_JSON
```

第一条只校验编写源；第二条登录本地教师并预览追加计划；第三条明确执行。认证值只能放在忽略目录的私有文件，不放入命令行或版本库。来源只允许完整课程的连续前缀扩展，不能跳过专题、删除旧章或改写旧内容。

工具核对原课程、课时 ID、双语五字段、目录和固定试卷版本。它只更新总课程元数据并创建后续章节，不对原章节发起 PATCH。旧章节有教师改动、课程已发布／归档、引用或身份不一致时停止，要求另行核对，避免覆盖教师编辑。

每次写入携带 `expectedDraftRevision`；服务端在锁定父课程的同一事务内检查版本和未发布状态。课程详情对可编辑者提供 `editRevision`，旧版 API 没有该字段时工具拒绝写入。原有不带条件的编辑请求保持兼容。该检查防止 GET 后教师修改或发布与追加操作交错。

每个请求独立提交，并非整个追加计划的单一数据库事务。开始前保存私有快照和内容摘要；逐章记录已确认的 ID 与固定版本。丢失响应或普通异常后，可以核对已有精确前缀继续追加，不重复创建；遇到不一致停止。SIGKILL 等硬终止可能遗留 `.lock`，须先确认没有存活的写入进程、核对私有记录和服务器状态，再清理该任务锁；不能删除导入日志重建课程。完成后更新原统一导入记录，保留追加前快照及回执。

历史六门专题的合并工具仍只合并 C1/C2 六门来源，再用追加工具加入新专题。不会因课程编写源增加 C3 而要求另建三门独立课。
