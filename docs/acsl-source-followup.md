## Intermediate 2024–2025 C3 Q6：正则表达式

原题英文在 `c_3_int.pdf` 第 2 页，中文在第 4 页；官方解析在 `c_3_int_soln.pdf` 第 2 页。原表达式为：

```text
[J-PT-V]*[^c^f-m]*[2468]
```

第一个字符类接受大写 J–P、T–V。第二个字符类开头的 `^` 表示取补集，后一个 `^` 是普通字符；它排除 `c`、`^`、`f`–`m`，并没有排除数字 `2`。两个 `*` 都允许空串。

| 候选 | 三段的一种完整匹配方式 | 结果 |
| --- | --- | --- |
| a `Jjp2` | 小写 `j` 被第二段排除 | 不匹配 |
| b `KULaazzz24` | `KUL` / `aazzz2` / `4` | 匹配 |
| c `L6` | `L` / 空串 / `6` | 匹配 |
| d `TTOOB8` | `TTOO` / `B` / `8` | 匹配 |
| e `dstxyz4` | 空串 / `dstxyz` / `4` | 匹配 |
| f `4` | 空串 / 空串 / `4` | 匹配 |

Python 与 JavaScript 两套整串匹配核验结果一致。正确集合是 **b、c、d、e、f**，原五个选项没有完整正确项。具体矛盾是：原题 C 写 `c,d,e,f`；官方解析右侧答案栏写 `C. b,c,d,e,f`；左侧推导却又说 b 在最后的 4 失败。
