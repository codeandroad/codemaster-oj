# ACSL Intermediate C1 教程扩写

日期：2026-11-12。承接 [双语课程、共享进度与真题关联](acsl-tutorial-integration.md)，本阶段扩写递归函数和程序追踪，不另建阅读或判题系统。

## 内容与教学设计

| 专题 | 三节课程 | 原创自测 | 真题关联 |
| --- | --- | --- | --- |
| 递归函数 | 基例与回代；调用树与复合调用；多参数状态、分支与取整 | 每章 3／3／4 题 | 12 道，按章分配 2／5／5 |
| 程序追踪 | 顺序赋值与数值操作；分支路径与边界反例；循环、旧值与终止 | 每章 3／3／3 题 | 8 道，按章分配 1／5／2 |

每个专题保留两份编写源文件，导入后成为一门中英课程。与已有四节数制课合计十节；课程地图中的其余 29 节仍待编写。这里完成的是 C1 基础学习顺序，不宣称三节程序追踪已覆盖所有数组、字符串或所有年份的组合题。

递归先从卡片分批累计建立定义，展示调用链、等待的运算及从基例回代的顺序；随后用完整调用树区分重复调用、不同输入和表达式中的必要贡献；最后用参数状态表处理局部参数与取整。例题结果用算术级数、独立展开式或另一种计算路径核对。

程序追踪逐条显示赋值后的状态，区分独立条件与互斥分支，用边界输入检验规则，再处理正负步长、零次循环和保存旧值。伪代码记号对照 [ACSL 官方说明](https://www.categories.acsl.org/wiki/index.php?title=What_Does_This_Program_Do%3F)：`int` 按向下取整解释，并明确它与某些编程语言同名函数在负数上的区别。例题和自测均原创，没有复制官方样题的完整解答。

图表由 Markdown 表格、文本调用树和 KaTeX 原生渲染，不使用 PDF 裁图。包含代码块的自测使用固定粗体题号，避免列表分块后重新从 1 开始。自测解析默认折叠，正式题答案仍按原整卷提交权限控制。

## 内容工具

校验与导入增加 `--unit number-systems|recursion|program-tracing`；默认仍为数制。`node scripts/check-acsl-tutorials.mjs --all` 检查所有已编写单元，同时核对完整 Intermediate 真题分类索引。

每个专题检查中英章节数量、题目与答案编号、Markdown 往返、公式编译和逐章题目映射。递归及程序追踪的 `checks.mjs` 执行固定的可信教材计算，并把结果与两种语言实际展示的代码、公式、表格和答案绑定；不会执行学生代码或文档中的程序。

导入记录按专题独立保存，保留原数制记录的键。重跑核对课程 ID、章节 ID、译文和固定试卷版本；已修改或已发布内容不会被静默覆盖。脚本只通过本地教师 API 创建未发布草稿。参数缺值、重复参数、未知专题、映射缺失或编号不一致会在导入前拒绝。
