# Paper 4 本地预览说明

本分支提供供学校练习和模拟考试验收的 **Python 3 首版**。普通 OJ 题目、提交、AC 积分和排行榜继续使用原有流程；Paper 4 试卷、草稿、阶段快照、运行任务与教师评分保存在独立的数据表中。自动用例可对每道大题给出 AC/WA 功能结果，**不会自动折算为 75 分成绩**；教师按阶段评分后发布总分。

## 本地启动与验证

在 Paper 4 worktree 根目录执行 `node scripts/start-paper4-preview.mjs`。脚本只启动 `campus-judge-paper4-preview` Compose 项目，默认使用 `127.0.0.1:3002`、数据库端口 `35433` 和独立的 `campus-judge-paper4-preview_database` 卷，不会重建现有 `campus-judge-local` 实例或连接 rslab。预览私密配置写入被 Git 忽略的 `deploy/.env.paper4.local`，演示账户写入被忽略的 `.campus-local/test-accounts.json`。脚本幂等加入**依据用户提供的试卷制作的英文三题改编样卷**；若预览里已有早期英文样卷，则通过修订草稿验证并发布新版，已有作答继续固定旧版，不会删除数据。验证时请选择列表靠前的英文样卷。仓库不收录原始试卷 PDF、评分 PDF 或 Word 证据模板；改编包包含题面转述及运行所需的文本数据。

启动后打开 `http://127.0.0.1:3002/login`。教师进入“Paper 4 实践评测”，可查看或新建试卷、导入结构化 JSON/ZIP 试卷包并预览、编写三道大题的阶段与分值、配置输入文件和测试，再运行参考答案。所有自动阶段的参考运行通过后，才能发布到班级。交卷后教师逐阶段评分及公布成绩。学生进入“Paper 4 练习”，可保存服务端代码草稿、运行当前大题、查看本次公开运行结果和生成的文本文件、保存不可覆盖的阶段检查点，并交卷。两处登录身份来自上述私密演示账户文件；请勿把文件内容提交到 Git。基于原卷制作新包时参见[制作指南](paper4-package-authoring-guide.md)。

可以用英文样卷第二题检查文件型运行：`TheData.txt` 有 72 行，程序按原练习要求向六种颜色文件追加内容。测试会预置一个输出文件，核查追加而非覆盖。每个用例在独立沙箱运行，反复运行不应累积上一次的内容。自动阶段的所有公开和隐藏用例通过才显示 AC；源代码结构、解释与证据等人工阶段仍须教师复核。教师发布成绩前，学生只能看到运行反馈，看不到评分和隐藏测试数据。

可直接选用 [`paper4-english-practice.json`](../examples/paper4-english-practice/paper4-english-practice.json) 或 [`paper4-english-practice.zip`](../examples/paper4-english-practice/paper4-english-practice.zip) 测试批量导入。JSON 是自包含文件；ZIP 内有 `manifest.json` 和由其明确引用的小型文本附件。服务器的 `POST /api/v1/paper4/imports/preview` 先检验并返回摘要，确认后再把 `createBody` 发给 `POST /api/v1/paper4/papers` 创建草稿。原始 PDF 与只含考生文件的 ZIP 不会被自动识别。字段格式、安全限制和扩展方式见 [导入格式](paper4-import-format.md)。

## 首版边界

- 仅支持 Python 3、班级范围的练习与模拟考试；试卷总分固定 75 分，教师须为每个阶段评分（包括 0 分）后才能公布成绩。自动阶段 AC 是功能检查结论，不是该阶段满分的证明。
- 草稿带修订号，跨标签页旧版本写入会被拒绝；阶段快照及发布后的试卷版本不可原地覆盖；提交后代码冻结。截止时，已保存草稿在访问时会由服务端冻结并留给教师批阅。
- 输入与生成文件首版限定为小型 `.txt`、`.csv`、`.dat` 文本文件，按清单及大小限制进入隔离执行器。可选教师驱动代码也在同一隔离执行器内运行，用于检查类和函数接口；驱动、隐藏输入及预期答案不返回给学生。
- 尚不支持原卷 PDF 导入、`evidence.doc` 或截图导出、正式 Cambridge 考试的离线监考/交付流程，也不声称自动评分足以取代人工审阅。

上线前仍需按设计草案完成正式题目授权、复杂正确解与错误解的评分比对、多人并发与故障恢复、备份恢复和完整考场流程核验。本地预览仅供功能与交互验证。
