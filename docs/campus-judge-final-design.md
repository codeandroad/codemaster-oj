## 1. 产品定位

- 校内本地部署的教学型 Online Judge，面向高中 Python 初学者，兼顾 ACSL Intermediate 与 CIE 9618 Paper 4 训练。
- 核心教学闭环：**学习 → 练习 → 自测 → 正式提交 → 结果 → 订正 → 教师跟进**。
- 三类角色：学生、教师、管理员。

<a id="visual-design"></a>

## 2. 视觉与交互规范

- 浅灰页面底、白色内容区、克制的蓝色主操作；不使用渐变、玻璃拟态、营销横幅、大型统计卡。
- 正文 Arial / 系统无衬线（中文系统字体回退）；代码使用等宽深石板灰。
- 编程工作区桌面端约 44%（题面）/ 56%（编辑器）分栏，各自独立滚动；全局侧栏默认收起。
- 学生题面以英文为主，附少量中文易错提示。
- 所有页面标注 `Prototype · Sample data`；未制作模块明确标"后续版本"，不留死链接。
- 教师与管理员左侧一级导航统一为英文；页面内部中文待完整中英文化时再处理。

<a id="identity-model"></a>

## 3. 身份与账号模型（方案一）

**身份档案与登录账号分离，身份先行、账号后绑。**

- 身份档案（学号/工号、姓名、班级）由管理员独立维护，**导入名单不受账号限制**；成绩、提交、订正记录始终挂在身份档案上，换账号/重置账号不丢数据。
- 用户通过**注册页一次性认领身份**：学号/工号 + 姓名 + 激活码 → 自行设置用户名与密码。管理员**不代建账号**。
- 日常登录无需重复验证身份，**无首次登录强制改密**；忘记密码 = 联系管理员重置。
- 未激活身份可入班、可被布置作业，在名单中显示"待激活"及激活码。

### 各页面分工

| 页面 | 职责 |
|---|---|
| 注册页 /register | 三步：验证身份（学生/教师切换）→ 设置账号 → 完成；固定示例：激活码已使用 / 已失效 / 身份不匹配，各含重新输入指引 |
| 登录页 /login | 日常登录；忘记密码指引；固定错误示例：空字段、凭据不匹配、账号不可用、服务暂不可用 |
| Admin → People & Identities | 身份档案列表（学生/教师 tab、搜索、激活状态筛选）；新建身份（无需账号，生成激活码）；详情：激活码+复制按钮、重新生成、关联/解除账号、编辑资料（姓名/编号/班级/备注） |
| Admin → Accounts & Roles | 账号只用于登录；无批量导入/新建账号按钮；"生成激活码"支持筛选、全选、批量生成、逐个复制、复制全部；编辑仅限角色与账号状态 |
| 学生/教师个人资料 | 入口统一在左侧栏底部；身份信息只读（提示联系管理员更正）；账号信息可自改邮箱、密码（≥8 位、两次一致） |

## 4. 学生端设计

- **工作台**：默认首页（示例身份 Emma Chen），学习、练习、作业与提交入口。
- **题库列表**：搜索、筛选、收藏外观、空结果与无权限固定视图。
- **编程工作区**：
  - P101 A+B（Standard I/O）；P104 Row Sums（Python Function）：接口 `def row_sums(grid):`，返回二维列表每行和、不修改输入；提示 "Return the result. Do not print it."；示例 `[[1,2,3],[4,5,6]] → [6,15]`。
  - Run Samples / Run Custom Input / Submit 三按钮分离且底部固定可见；自定义运行无期望输出时显示"执行完成但尚未判定"，**不得显示 AC**；样例通过不代表正式评测通过。
  - 离开有临时编辑内容时弹确认，不承诺保存。
- **作业详情（S06）**：作业题目、进度与提交入口，保留 A03 示例。
- **提交记录**：SUB101042（WA 75/100，6/8）与 SUB1048（订正 AC 100/100，8/8）构成订正链路；隐藏测试只显示允许公开的结果。
- **学习路径（S05）**：路径列表/详情/章节页；Python Foundations 的 2D Lists 英文教学内容（矩阵示例、分步行和、Checkpoint、P104 练习入口）。
- **订正本（S08 Review Notebook）**：区分原活动 SUB101042 与独立订正 SUB1048；短笔记、代码对比、教师反馈、再次练习；提交详情可加入订正本；订正不覆盖原成绩。
- **计时训练（S07 Timed Practice）**：列表、T01 规则、开始确认、固定倒计时工作区、结束确认、未发布/已发布结果、赛后订正预览；工作区按训练来源显示题目导航、固定剩余时间、Draft only/Submitted/Judging 状态。

<a id="teacher"></a>

## 5. 教师端设计

- **工作台**：教学活动入口与固定进度摘要。
- **Classes & Students**：可切换三个班级（高一1班、高一2班、CIE 9618 P4），各班显示各自名单与进度；支持新建班级（名称必填查重、可勾选已有学生，学生保留原班级）；名单含 Account 列（已激活/待激活+激活码）；无账号身份也能入班。
- **作业管理与编辑**：Problems 页签支持题库/分组/搜索去重选题、导入、逐题分值、调序、打开统一编辑器、移除；Applicable list 支持搜索、全选/清空、勾选适用/豁免与实时计数；A03 进度矩阵（475/600 固定示例），矩阵抽屉展示原提交、订正、学生笔记与可临时编辑的教师反馈。
- **Problem Banks 与分组**：见[题目与题库规则](#problem-rules)。
- **Import Center**：Problem import / Member import 双向切换；见[导入规则](#import-rules)。
- **统一题目编辑器**：见[题目与题库规则](#problem-rules)。
- **学习内容**：路径/资料列表、新建、章节编辑/增删调序、正文编辑、学生预览；练习选择器按题库→分组→搜索/勾选选题，同题去重。
- **计时训练管理**：列表、新建/编辑、题目与分值、规则、学生预览、进行情况、延期/结束/重判/发布的独立确认预览。
- **教学报告**：明确筛选、带分母指标、行动名单、题目/学生下钻抽屉、保留返回筛选。

<a id="admin"></a>

## 6. 管理端设计

- **People & Identities** 与 **Accounts & Roles**：见[身份与账号模型](#identity-model)。
- **Import Center**：管理员账号导入与教师成员导入共用四阶段流程。
- **Judge Service**：节点、队列与故障固定快照；故障不转成学生 WA/0 分；不运行真实判题或自动刷新。
- **System Settings**：站点、运行环境、备份恢复计划与审计记录；操作仅预设确认和结果。

<a id="judging-semantics"></a>

## 7. 评测与结果语义

- 13 种固定评测状态由工具栏手动切换、不自动推进：尚未运行、样例通过、公开输出差异、Waiting、Judging、WA、AC、CE、RE、TLE、MLE、OLE、System Error。
- **System Error 不记为 0 分**；系统故障不当作学生错误。
- 公开样例通过不等同正式 AC；隐藏测试不暴露不允许公开的内容。
- 原提交与订正提交分开，订正不覆盖历史结果。

<a id="problem-rules"></a>

## 8. 题目与题库规则

- "Problem Management" 为 **Problem Banks**：题库列表、新建空题库、题库详情、空态。
- **统一编辑器**：手工题、已有题、导入题共用同一套编辑器，点哪道开哪道。
- **测试维护**：公开样例与正式测试分开；支持添加、编辑、复制、删除；标准 I/O 题编辑输入/期望输出，函数题编辑参数/期望返回值；单文件就地替换、批量补测试后返回该题测试页。
- **分组**（题库内部章节/分组）：
  - 一道题可属于零个、一个或多个分组，多组只引用不复制。
  - **添加到分组**保留原有归属；**移动到分组**明确来源与去向，确认前展示"从哪里移出、向哪里加入、哪些保留"；**从本分组移除**只删本组归类。
  - **未分组**是无任何真实分组归属的视图，不是可与分组同时勾选的实体。
  - 分组调整不改题目内容、判题规则、发布状态、权限，不影响已有作业/提交/成绩。
  - 入口：题目行分组标签（多组显示前两项 +N）、行内"管理分组"、批量工具条、未分组视图"分配分组"、编辑器入口、已有题目抽屉选目标分组、导入结果"整理分组"；跨题库混合选择时提示"请选择一个题库后批量整理分组"。
  - 统一"管理分组"弹窗：单题与批量复用，可搜索多选、可新建分组，确认摘要区分新增与已存在归类；确认按钮用具体动词。
  - 分组管理：新建、改名（会话内同步）、解散（不删题目）。
- 本地 A+B 题读至 EOF，`0 0` 不是终止条件。

<a id="import-rules"></a>

## 9. 导入规则

- **通用导入四阶段流程**：选择文件与去向 → 预览题目 → 确认导入 → 结果页；去向支持"创建新题库"或"加入已有题库"；文件树/来源/格式说明仅作折叠辅助内容。
- **成员导入**：目标班级下拉支持三个已有班级、不指定班级、按文件"班级"列（不存在的班级标记"将自动创建"）；无账号的学生建立身份档案并入班，标记"建档入班 · 待激活"及激活码；支持浏览器端解析 Excel（xlsx）。
- 题包识别与本机校验/发布按预设示例展示，不做真实校验。

<a id="technical-boundaries"></a>

## 11. 技术边界

- 仅组件内临时状态与固定示例常量；**禁止**后端、API、数据库、真实鉴权、代码执行、判题、计分、排名、持久化、定时器、轮询、WebSocket、AI。
- 不使用 localStorage / IndexedDB / Cookie 伪造状态。
- 唯一例外：成员导入允许浏览器端 Excel 预览解析；不扩展为真实题包校验、服务端导入、文件存储或真实建档入班。
- 注册、登录、激活码生成等只在原型内展示，不创建真实账号、不承诺保存或真实失效。
- 技术栈：TanStack Start v1 + React 19 + Tailwind v4；路由文件每页独立 head 元数据。
- 注册/登录的示例场景与校验保留在共享页面，原生 label 表单 + 内存状态，所有设备尺寸同一流程。
